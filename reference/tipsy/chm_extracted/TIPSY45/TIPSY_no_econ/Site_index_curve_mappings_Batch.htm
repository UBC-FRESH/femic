Site index curve mappings, Batch

If you have species/ FIZ The Forest Inventory Zone(s) that fall within the forest cover polygon. FIZ zones were developed to provide a broadly based ecological classification of the forestland in British Columbia. FIZ zones closely follow the early Biogeoclimatic zones developed by Dr. Krajina. The province of British Columbia is split into 12 FIZ zones. combinations that aren't listed, you can add your own site index curve mappings at the top of the dialog box. Just type the species code in the Input Code field, select a FIZ from the Input FIZ group and then select a substitute species from the drop-down list. You'll see which site index curve this species uses. Finally click the Add Mapping to Current List button and your new mapping will appear in the list.

If you don't want a code as part of the current site index curve mappings you can select it from the list and then click the Delete Mapping button.

If you want to overwrite a mapping, you don't have to delete the current one first. Just create a new mapping and add it, and you'll see a message that asks if you want to overwrite the current mapping.

Certain common species codes (such as FDC) have an assumed FIZ built right into the code (in this case, the “C” indicates “coastal”).  When users try to do BatchTIPSY runs without providing a FIZ for these particular species, the program generates a warning.  It was felt that for these species, this warning is not necessary, so we added a mapping for “None” (which will repress a warning if no FIZ is provided) for the following species input codes: CWC, CWI, FDC, FDI, HWC, HWI and PLI.

BatchTIPSY displays current mappings in the bottom half of the Site Index Curve Mappings dialog box..

The Reset All to Default Mappings button resets both the site index curve mappings and the volume mappings to the ministry defaults (recommendations), regardless of which dialog box you are in.  

This paragraph is particularly relevant for Woodlot users. When using command-line arguments, the user has the option of specifying either a .btp file or the old DOS command line (input file, output file, format file, .dat files). Specifying a .btp file will load it into the program as described above. If the old DOS command line is used, the mapping information in the .dat files will override any Ministry defaults.

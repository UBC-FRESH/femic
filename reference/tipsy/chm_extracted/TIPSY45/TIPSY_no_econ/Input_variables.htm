Input variables, Batch

Here you can specify column numbers for:

  • Table number. This can be any number you assign.

  • FIZ The Forest Inventory Zone(s) that fall within the forest cover polygon. FIZ zones were developed to provide a broadly based ecological classification of the forestland in British Columbia. FIZ zones closely follow the early Biogeoclimatic zones developed by Dr. Krajina. The province of British Columbia is split into 12 FIZ zones. (Forest Inventory Zone).

  • Area - is the number of hectares that the stand occupies.

  • Stand Regeneration options. For regeneration method, code your input file with a P (planted), an N (natural) or a C (clumped). The Regen. Delay default is 2 years for natural stands, and 0 years for planted stands. Use the Custom Regen. Delay to input other delays. See Stand Regeneration Options for information on initial density and regeneration delays.

  • Variable retention

  • Util. (DBH) limit If you don't have merch. limits in your input file, BatchTIPSY defaults to 12.5+.

  • OAF 1

  • OAF 2 TIPSY recently changed from using percentages to using factors to describe OAF levels. If you happen to have percentage values in an older input file, TIPSY can still read them. For example, if your input data file has values of 15 and 5 for OAF 1 and OAF 2, TIPSY translates these into factors of 0.85 and 0.95. This is a temporary feature for your convenience.

  • Armillaria in ICH Use L, M or H in your input file for low, medium and high levels of armillaria.

  • NOTE:  Previous options for Decay, Waste, and Breakage OAFS have been removed from TIPSY.

  • PCT density. See Initial Density, PCT and CT Density Options for more information.

  • Fertilization

  • Commercial Thinning. If you select this option, an optional dialog box appears entitled Commercial Thinning Variables.

You can also input species-specific coefficients for snags and coarse woody debris, but these options are available from the Edit menu only, whenever a batch file is open. All species are listed.

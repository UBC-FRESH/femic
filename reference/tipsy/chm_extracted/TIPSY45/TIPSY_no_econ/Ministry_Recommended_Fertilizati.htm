Background

The Ministry Default Response Models in TIPSY are based on data from experimental research plots in BC.   These plots were fertilized by hand to ensure 100% coverage and maximum response.   Operational application practices often result in lower fertilizer effectiveness due to greater variability, e.g., rate and coverage inconsistencies, etc.   An 80% effectiveness setting is normally recommended when using Ministry defaults and other research-based response models.

Consult the Forest Fertilization Guidebook web site for additional information on biological factors, application age, stand priority, and operational factors.

Default Response Models by species

TIPSY does not provide default response models for every species, only the following five.   The default response for all other species is zero.   The default response model for each species is specific to one application rate.

The tables below document Ministry default response models.   These relationships were generated by TASS II for stands planted with 1200 trees/ha. Each covers a range of sites and potential application ages (years since planting); TIPSY interpolates within.

TIPSY uses % gain to elevate yield in response to fertilization.
The % gain within TIPSY's standard 10-year response period is calculated as:


Total volume gain (m3/ha) = fertilized growth – untreated growth
Total volume gain (%) = (1 - fertilized growth/untreated growth) x 100

See Fertilization: Response Implementation for more detail.

Hemlock (coastal)

The default response is 0% for all sites and ages because field research has shown that western hemlock response is quite inconsistent, i.e., heavily site dependent. For example, young hemlock stands growing on sites not prone to salal in the vicinity of Port McNeill (northern Vancouver Island) respond to applications of N + P. Research plots fertilized at age 0 and again at age 5 produced an extra 18 m3/ha (assuming 1200 planted trees/ha) 10 years after planting. Users can create their own custom response model(s) for such sites.

Consult the Forest Fertilization Guidebook web site for additional information on biological factors, application age, stand priority, and operational factors.

Sitka spruce (coastal)

Very recent and limited data suggest that Sitka may be as responsive as Douglas-fir. Consequently, TIPSY uses the coastal Douglas-fir default response model for Sitka spruce.

Note that the Forest Fertilization Guidebook of 1995 does not recommend fertilizing Sitka spruce - but it does report that limited local experience indicates that it can respond to fertilizer, particularly if stands are chlorotic. Fertilization may also increase the incidence of leader attack by the spruce weevil (Pissodes strobi Peck).

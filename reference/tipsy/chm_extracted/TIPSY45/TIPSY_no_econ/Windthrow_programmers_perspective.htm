Windthrow: Programmer's perspective

Windthrow calculations adjust the crown cover % and edge length used in subsequent variable retention calculations.  To do this, the crown cover loss factor (CCWT) first must be calculated.  CCWT is the percentage of retained crown cover lost to windthrow.  You can enter the CCWT value directly by selecting the "User Specified" location model.

If you select a geographic location model to calculate CCWT, a logistic regression model value (LOGIT) is computed.  This is based on the values entered on the Windthrow dialog and on the specific model chosen.  The computation is as follows:

LOGIT = b0 + (Bearing * b1) + (Mean Wind Speed * b2) + (Directional Exposure * b3) + (Topographical Exposure * b4) + (Elevation * b5) + (Time Since Harvest * b6) + (Top Height of the Retained Group * b7).

The geography, climate and of the study areas for the derivation of these logistic regression models are documented in Lanquaye and Mitchell 2005.  The models coefficients are hard-coded into TIPSY and cannot be changed.  These coefficients and the mean values for the key variables and locations are listed below:

The mean values are the default values in TIPSY for each model and can be changed.  Note that Time since Harvest is the same as the years since disturbance, or TIPSY age.  Also - as with variable retention - in all windthrow calculations the residual stand top height value will be adjusted for regeneration delay.  That is to say that the trees continue to increase in height during any regeneration delay.

From this, the predicted windthrow probability is computed as:

WTPROB = exp(LOGIT)/(1 + exp(LOGIT))

Derivation of CCWT from WTPROB is dependant upon the methodology chosen for calculation of variable retention.  If the user has chosen the formula method of calculation and has specified that 100% of the area is dispersed trees, CCWT is calculated as:

CCWT = WTPROB * Crown Loss * Area Loss * Spacing Factor/ 0.2

where the Spacing Factor is the square root of:

10000 / (crown cover % / 100 / avg. crown area) / (residual stand top height)

For every other variable retention calculation method, an unadjusted CCWT value is first computed:

CCWT = (WTPROB + 0.1) * Crown Loss * Area Loss

This value must then be adjusted by group shape, as only the outer 25 metres of the area are subject to windthrow calculations.  If the variable retention methodology is User Specified, group size determination is not possible and the computed CCWT value is left unadjusted.  Otherwise, the area of the group in the outer 25m is calculated as follows.

For all but the circular shaped groups, an aspect ratio is determined as follows:

Square group: aspect ratio = 1

Rectangular group: aspect ratio = rectangle dimension (e.g., if the rectangle is 8x1 then the aspect ratio is 8).

Irregular group: aspect ratio = 12

Formula methodology; aggregate group: aspect ratio = 2.5

Then, the length and width of the group are calculated as:

Side A = square root of group area  * aspect ratio

Side B = square root of group area  / aspect ratio

From both sides, 50m is subtracted (i.e., 25m from both ends).  The new side length is that portion of the original side that is 25m in from both ends  If either new side is less than 0, it is made equal to 0.  Then the inner-area is calculated as:

Inner Area = New Side A * New Side B

This Inner Area represents the original area with a 25m strip cut away on all 4 sides.

For circular groups, the radius of the circle is calculated as:

r = square root of group area / pi

Then r is modified to strip off the outer 25m (if r < 25m then r = 0) and calculate the new inner area:

Inner Area = pi (r 25)2

Once we have calculated the Inner Area, the proportion of the original area that lies outside this inner area is calculated as:

Outer Area Proportion = (Original Area Inner Area)/Original Area

With this proportion, we can then adjust the computed CCWT as follows:

Amended CCWT = Original CCWT * Outer Area Proportion

This is the value that will be shown on the TIPSY dialog as Crown Cover Loss Factor.

Now that a CCWT value has been computed, we can then go on to compute the adjusted crown cover % and edge.

Adjusted crown cover % = orig. crown cover % - (orig. crown cover % * amended CCWT)

Adjusted group size (area) = orig. group size (orig. group size * amended CCWT)

The edge length calculation will be done as in the original variable retention model, but using the adjusted crown cover % and group size.  For more information on edge length calculation, see Variable Retention.

Because there is no stand volume prior to planting, the algorithm does not have to concern itself with modifying the stand before delay age.  After delay age, the change to crown cover % is a constant.  Therefore adjustments to the crown cover % are computed at delay age and then applied the same way for every row.  The edge length is calculated for each row in the table up to age 10 at which point it becomes a static value.

We have developed VR coefficients for only four species in TIPSY. If you use variable retention with windthrow for any other species, the program automatically makes substitutions. See Table of VR species substitutions.

Format file additions for DOS interface

Several keyword additions have been made to the format file used with BatchTIPSY’s DOS interface in order to accommodate windthrow.  Each keyword is followed by two numbers which signify the start and end columns for that input parameter on each line of the input file.  For example, AGE 72 - 73 means that the age will be read in between columns 72 and 73, inclusive.  The new windthrow additions are:

WT_MODEL n1 model

WT_BEARING  n1 - n2 bearing / CCWT

WT_MWS  n1 - n2 mean wind speed

WT_DIREX  n1 - n2 directional exposure

WT_TOPEX  n1 - n2 topographical exposure

WT_EVEL  n1 - n2 elevation

WT_CL  n1 - n2 crown loss

WT_AL  n1 - n2 area loss

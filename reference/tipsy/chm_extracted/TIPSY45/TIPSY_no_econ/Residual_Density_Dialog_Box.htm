PCT Residual Density Dialog Box

Pre-commercial thinning (PCT) Residual Density settings are accessed from Stand Specifications, using the button below the PCT checkbox in the Treatment section.

Enter the desired post-PCT Residual Density as either Density (trees/ha) or Spacing (m).   Alternatively, a button is provided to estimate Residual Density from Existing Stand data, post-PCT.

NOTE:  The timing of PCT is fixed within TIPSY at a Top Height 4 metres in the interior and 6 metres on the coast.

Avoiding lodgepole pine height repression with PCT:   When working with extremely dense stands of natural lodgepole pine subject to height repression (> 13,825 trees/ha initial Density), the Residual Density dialogue box displays the PCT prescription that avoids height repression.  Checking the associated box indicates the specified critical height threshold (PCT timing) will be met, although the user may select any residual density below the specified density threshold.   When the box is left unchecked, TIPSY applies its repression effects model.

Select PCT pre-post data in the Preferences Menu to display pre- and post-PCT stand conditions within Yield Tables.

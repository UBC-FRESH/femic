Stand, Stock and VPT View Options

The Stand, Stock and VPT View Options dialogue box appears whenever a Stand, Stock, VPT Output Table is requested using the Tables Menu or the Toolbar icon shown above.  Subsequently,  this dialogue box can be accessed with the Pencil icon on the Toolbar.

This dialogue box is used to select any combination of the following three options.   Selecting more than one produces a composite table.

Stand Table (# trees):  number of live trees (stem count) within 5 cm DBH classes.

Stock Table (volume):  merch. volume 12.5+ cm (m3/ha) within 5 cm DBH classes.

Volume per Tree (VPT) Table:  mean merch volume 12.5+ per tree (m3/tree) within 5 cm DBH classes.1

Total columns may not equal the sum of the DBH classes, due to rounding.

Due to the width of these table, columns may be missing when printed.   Reducing Font size in the Preferences Menu and/or changing to Landscape in your Printer Properties dialog box may help.

1 Note that the merch. volume per tree 12.5+ is stand merchantable volume (12.5+) divided by the number of merchantable trees (12.5+).   In comparison, the avg. vol./tree variable in a custom table is the total stand volume (0.0+) divided by the total number of trees.

Preferences allow users to set and save several program display options.

Note: the Make Default option and Preferences serve different purposes.  Preferences only affect the way the program displays information, while Defaults represent stand specifications.

Metric  /  Imperial

TIPSY's internal database is metric, but it can also convert outputs to US Imperial measurements.   There are exceptions, e.g., lumber is always expressed in board feet.  US Imperial measurements are not available in BatchTIPSY.

Toolbar / Status Bar

The Toolbar and Status Bar (at the bottom of the main window) can be toggled on and off independently, depending on user preference.

Font...

Font style, colour, and size for screen and printer output can be changed.   In particular, reducing font size can help when working with wide tables that exceed screen or printer capacity.  Changing Orientation to Landscape in Page Setup may also help.  Or, use the Custom Table option to eliminate unwanted columns.  Note Font preference can also be accessed with the 'A' icon on the Toolbar.

Single View

With Single View toggled off, multiple output windows can be opened for each regime.   TIPSY's large number of output options can quickly bury the user in windows.   Toggling Single View on restricts each regime to one output window at a time.  Existing output windows for a particular regime are automatically closed when a new one is opened.

No Start-up box

Suppresses display of the Start-up Box when TIPSY first opens.

Display CT Values

Displays a Commercial Thinning (CT) Harvest summary at the bottom of Yield Tables.

PCT pre/post data

Adds two rows of data within Yield Tables, at time of PCT, describing pre- and post-PCT stand conditions.   Not available with multiple species.

CT pre/post data

Display two rows of data at the bottom of Yield Tables that describe the stand immediately before and after CT (commercial thinning).

Table Specs Precision

Sets the number of decimal places reported for age and height only.  It does not apply to other output variables.

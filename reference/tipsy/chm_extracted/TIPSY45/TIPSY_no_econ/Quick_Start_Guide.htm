Quick Start Guide

Follow the steps below to generate yield tables for an individual stand regime (project) using TIPSY's interactive mode.   To generate multiple yield tables from large multi-stand databases, like those used in forest-level analyses, use BatchTIPSY instead.   Also see: Selecting the Right Model.

STEP 1:   TIPSY requires stand establishment information to generate yield tables for a regime (project).  Users edit this information using the four dialogue (settings) boxes listed below.   These are automatically displayed sequentially when creating a New project.   For editing existing projects, they can be accessed individually through the Edit Menu and Tool Bar icons.

  1. Project Title and Stand Geography

  2. Species Specifications

  3. Stand Specifications

  4. Table Specifications

The SAVE command saves all these project settings to a .TIP file A TIPSY file containing the user-defined settings required to generate output tables for a unique stand using interactive TIPSY. It does not contain the output tables themselves, only the settings required to generate them., which re-populates these settings when opened later.   A .TIP file A TIPSY file containing the user-defined settings required to generate output tables for a unique stand using interactive TIPSY. It does not contain the output tables themselves, only the settings required to generate them. does not contain yield tables, it only contains the settings for creating them.   

STEP 2:   Select, configure, and view the many types of Output Tables accessible through the Tables Menu and Tool Bar icons.   Output can also be Printed, Exported as text files, or directed to software integrated with TIPSY, i.e.,  PLOTSY for graphing, FAN$IER for economic analysis, and CBM for carbon budgeting.

NOTE:   Operational Adjustment Factors (OAFs) and multi-species yields are two key concepts that are frequently misunderstood.   They are important topics to understand before using TIPSY for operational decision support.

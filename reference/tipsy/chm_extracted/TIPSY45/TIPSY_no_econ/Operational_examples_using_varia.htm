Variable Retention: Operational Examples

Example 1

We want to remove 85% of an existing 90-year old stand of coastal Douglas-fir (site index 30) with the intention of leaving the remaining 15% to develop into old-growth. At the time of harvesting, the trees have a top height of 37.5m, where 90% of the retained area is aggregated (with an average group size of 1000m2), and 10% is dispersed trees, with an average crown area of 20 m2. The harvested portion of the stand (85%) would be planted and left for another 90 years. To do this in TIPSY, in the VR dialog:

1. Set Residual stand top height at entry to 37.5m.

2. Set Crown cover retained to 15% (the area left unplantable due to the presence of old-growth).

3. Select Formula for the edge-length calculation method.

4. Set the Crown cover of Aggregated groups to 90% (this will automatically adjust the percentage crown cover of dispersed trees to 10%).

5. Set the Avg. group size to 1000m2.

6. Set the Dispersed Avg. crown area to 20m2.

This should give a calculated edge length of 335.9 m/ha which will generate a variable retention adjustment factor (VRAF) of 0.77 100 years after harvesting. You can then use the various tables in TIPSY to see the values predicted for the stand after 90 years. Use the Custom Table to view the impact of the VRAF on merch. volume 12.5+ at any age.

Example 2

In the above example, we might have a stand with a regeneration delay Natural stands: years from disturbance (fire, logging) until the first successful seed year. Plantations: years from disturbance (fire, logging) until planting of 2 years. Because of this delay, TIPSY must calculate the total age at 37.5m (age 80), add the 2 year delay (age 82), and calculate the height at that age (38m). This height is used in subsequent calculations, resulting in an edge length of 334.7 m/ha. Since the edge length difference between this and the previous example is only 1.2 m/ha, the VRAF is still 0.77 at age 100 since VR harvesting.

Example 3

We want to remove 40% of an existing 100-year old stand of lodgepole pine (site index 17.5, Nigh 1999 site curve equations). At the time of harvesting, the retained groups have a top height of 23.2m with an average size of 1500m2 of circular shape. To do this in TIPSY, go to the VR dialog, and:

1. Set Residual stand top height at entry to 23.2m.

2. Set Crown cover retained to 40%.

3. Select Geometry for the edge-length calculation method.

4. Set the Average group size to 1500m2.

5. Set the Group shape to circular.

This should result in a calculated edge length of 366.1m/ha which generates a VRAF of 0.58 100 years after harvesting.

Please note that, as mentioned in 'How TIPSY applies VR', application of VR will affect your initial density. Initial density refers to the density without the affect of variable retention or any other adjustment factors. Please adjust the density if necessary.

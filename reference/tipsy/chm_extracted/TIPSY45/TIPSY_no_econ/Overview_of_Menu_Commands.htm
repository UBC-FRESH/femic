Overview of Menu Commands

TIPSY's main window includes the familiar Main Menu Bar across the top containing six menu items:

File Menu Alt+F

Edit Menu Alt+E

Tables Menu Alt+T -- appears once a stand is defined or .TIP file A TIPSY file containing the user-defined settings required to generate output tables for a unique stand using interactive TIPSY. It does not contain the output tables themselves, only the settings required to generate them. is opened.

Preferences Menu Alt+P

Window Menu Alt+W

Help Menu Alt+H

Each pull-down menu above can be accessed with a mouse, or by pressing the ALT key in combination with the underlined letter (e.g. ALT+E pulls down the Edit menu).  To select command within each pull-down menu, press its underlined letter or click on the command.

Many of these same commands can also be accessed via the Tool Bar icons directly below the Main Menu.   Hovering the mouse pointer over each icon reveals its text label.

About Custom Tables

The Custom Output Table is accessed through the Tables Menu or the Tool Bar icon above.  A Custom Table is a custom Yield Table reporting user-selected variables.  Several TIPSY variable are only reported in Custom Tables.

Custom View settings  

Variables are selected in the Custom View dialogue box, which can be re-accessed later with the Pencil Icon in the Toolbar.    The list on the left side of the dialogue box contains all the variables available for selection.   To select variables, move them to the list on the right with the Add buttons.   Use the Remove buttons to de-select them.

TIPSY Age and Top Height are automatically included in every table.   Table Specifications apply.

The Sets of Variables drop-down is used to subset (reduce) the variable list (on the left) to reflect the selected category.

The Up and Down buttons re-order columns in the table.  TIPSY automatically provides grouped table headings when similar variables are grouped together.  E.g., if Vol. Merch 12.5+, 17.5+ and 22.5+ are listed together, TIPSY will generate a group heading, Volume (m3/ha), over the three variables.

Click OK to view the table.

Variables Available

The selection list contains many of the variables from standard Yield, Lumber, Log, Carbon/Biomass, and Jobs tables, plus a number of others unique to Custom tables, e.g.,

  • Various age definitions.

  • Custom minimum DBH limits (utilization levels) applied to Merchantable volume, MAI, Basal Area,  DBHg, and Tree Count number of living trees per hectare, 0.0+cm and larger, unless otherwise specified..
    Select and Add any of the associated "User" variables (i.e., Vol User, Basal Area User, etc) to open the User Utilization Level dialogue box and enter a custom unitization level (minimum DBH limit).   This value will apply to every "User" variable hereafter, in the current project, and cannot be changed.

  • Crop tree statistics for Merchantable volume, Basal Area, and DBHg.
    Select and Add any of the associated "12.5+ Crop" or "12.5+ Crop 250" variables.  The latter reflect the largest 250 tree/ha (>12.5cm DBH).   Select any of the former to open the Crop Tree Statistics dialogue and define a custom number of crops trees (>12.5cm DBH).

  • Lumber yields by grade in three formats,
    and Juvenile wood volume.

  • Coastal Log Grade Volumes as reported in Log Tables
    and Interior Industrial Log Grade Volumes.

  • Variables used in fire hazard prediction models.  See the Fire group in the Set of Variables list.

  • OAF Impact A TIPSY output: The total impact (% based on merch 12.5+) of all TIPSY OAF adjustments applied. and Var. Ret. Adjust. A TIPSY output: the total impact (% based on merch 12.5+) of all the TIPSY Variable Retention Adjustments applied. (Variable Retention Impact) values (%).

Graphing the Data

After preparing a Custom Table, click the Plot icon in the Toolbar.  Graphing data from a Custom Table follows the usual TIPSY plotting process.   Note that the Column Group drop-down list in the Add and Remove Series dialogue box (first step in plotting) functions like the Set of Variables drop-down list in this (Custom View) dialogue box.

Derived Variables

Many variables in the managed stand yield table can also be derived from the stand and stock tables.  However, there is a small loss of resolution, because trees are sorted and grouped by DBH classes.   E.g., all trees in the 12.5 to 17.5 cm diameter class are assumed to have a DBH of 15 cm.   TIPSY has no individual tree data in its database.   Deriving data from the stand and stock tables expands the selection of variables available without enlarging the database.

The Custom table uses the stand and stock tables to derive Basal Area 0.0+ and DBHg 0.0+. These should be the only two variables that differ between the custom and yield tables.

These variables in the custom table are the only variables taken directly from the yield table database:

  • Crown Cover

  • Crown Length/Ht (LC)

  • MAI - Total 0.0+ and Total 7.5+

  • Volume - Gross 0.0+, Total 0.0+, Total 7.5+

Standard Format Table, Batch

The Standard BatchTIPSY Table displays stand description details and headers. The four columns displayed for each record are:

  • Age since disturbance (TIPSY age). See Ages Defined in TIPSY for more information.

  • Merchantable volume. If your input files doesn't specify merchantability limits, BatchTIPSY defaults to 12.5+. See Merchantability Limits for information on limits available from TIPSY's database.

  • DBHg

  • Top Height

The Custom table in BatchTIPSY allows more flexibility.

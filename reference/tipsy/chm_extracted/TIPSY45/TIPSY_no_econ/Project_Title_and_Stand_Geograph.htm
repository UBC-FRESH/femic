Project Title and Stand Geography

This is one of four main dialogue boxes used to edit the settings required to generate output tables for a unique stand.   It is accessed through the main Edit Menu; there is no Toolbar icon for this.

This box contains the following settings:

Project Title:   A descriptive title for the current settings.   It appears on printed tables and serves as an option for naming curves on a PLOTSY graph.  

Forest Region and Forest District:  The stand's location within now-outdated provincial ministry administrative units.

Biogeoclimatic Zone:  The Biogeoclimatic Ecosystem Classification (BEC) Zone for the stand.

Slope:  the stand's average slope [%] average slope of the stand's terrain (%).

You can save your own custom defaults for the settings in all four main dialogue boxes using the Make Default command.

NOTES:  Region, District, BEC, and Slope DO NOT affect TIPSY yields.  However, they are exported to FAN$IER where they control many default costs.   Also, be aware it is possible to select coastal species within interior forest districts and BEC zones, and vice versa; this intentionally allows maximum user flexibility.

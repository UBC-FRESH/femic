New...

Use this command to create a new, untitled file.   After selecting New, a series of dialogue boxes will appear populated with defaults.   See Quick Start Overview for more details.

Open...

Use this command to open the project settings from an existing TIPSY .tip file.

Close

This command closes the active file/document (the one that is highlighted), but not the program.

Run (BatchTIPSY)

Select Run to process a Batch file after completing edits to the input file.

Save

Use Save to name and save a newly created project as a .TIP file A TIPSY file containing the user-defined settings required to generate output tables for a unique stand using interactive TIPSY. It does not contain the output tables themselves, only the settings required to generate them., or overwrite the settings within an existing file.

Save As...

Use Save As to rename and save the current settings under a different name, i.e., create a new project based on an existing project.  This is particularly useful when creating a treated regime from an untreated regime.

Make Default

This replaces TIPSY's project defaults with the current project settings.   These defaults automatically populate TIPSY's project settings each time a new project is started with the File, New command above.

Note, if TIPSY is installed on a network drive, rather than on a workstation, all users on the network share the same defaults.   See TIPSY Program Files for an explanation of how the .ini files could cause problems with default settings.

Change Database Directory..

This feature is not available yet.

Start BatchTIPSY

This opens BatchTIPSY for processing input files containing multiple stands.

Send to FAN$IER..

This exports TIPSY stand yield data to FAN$IER, an independent economic analysis program packaged with TIPSY.  FAN$IER will automatically open in a separate window and load data from the selected TIPSY regime.   FAN$IER's Help explains how to use this powerful economic analysis tool.

Send to CBM..

This exports relevant stand yield data to CBM, an independent, operational-scale Carbon Budget Model developed by the Canadian Forest Service.   Users must first install  Carbon Budget Model version 1.2.4158.75 or greater.  Note, the on-screen TIPSY to CBM form has a separate Help (instructional) document.

Plot...

The Plot command, or icon, opens Plotsy, an independent plotting program packaged with TIPSY and other Ministry GY software.   Initially, the Add or Remove Series/Themes dialog box will open to enable selection of the initial variables to be plotted.   The selection list is limited to the variables displayed in the currently active TIPSY Output Table window.   Plotsy will then open automatically with the selected variables loaded.   Plot variables from one source at a time (e.g., TIPSY, SiteTools, etc) to avoid potential conflicts.  Plotsy's Help explains how to use this powerful plotting program.

Export...

Use the Export option to create and save a text file containing the Output Table data.   This can be imported into another application for processing, plotting or including in a report, etc.   For more information, see Exporting TIPSY data.

Print...

The Print command prints the current, or highlighted, table to your default Windows printer. The Stand Description and the file name will appear at the top of each printed table.

If columns are missing from wide tables, consider reducing Font size and/or changing Orientation to Landscape in Print Setup below.

Print Setup...

This opens the Print Setup dialogue box where you can specify different printers, portrait or landscape orientation, etc.

Exit

To close TIPSY completely, click on Exit or press X on the keyboard when the File menu is displayed. Other methods to exit TIPSY include:

  • Press ALT+F4

  • Click the red X in the extreme upper right corner of the main TIPSY window.

  • Click the TIPSY icon in the extreme upper left corner of the main TIPSY window and select Exit from the drop-down menu.

In TIPSY's interactive mode, Variable Retention (VR) settings are defined through the Variable Retention dialogue box accessed through the OAF section of  Stand Specifications.

The Variable Retention dialogue box defines the three pieces of information needed to calculate the Variable Retention Adjustment Factor (VRAF) applied to the regenerated stand yields being projected by TIPSY:

  1. Residual stand top height at entry (VR harvest timing),

  2. Crown Cover (CC) retained (%) by the VR harvest, and

  3. Total edge length created by the VR harvest.

Residual stand top height at entry

Enter the top height of the existing stand at VR harvest.

Crown cover (CC) retained (%)

Enter the crown cover (%) retained by the VR harvest.  I.e., the proportion of the total stand area occupied by the crowns of the retained trees.   This value can be entered directly, or calculated from basal area of the retained trees, as follows.

Calculate CC % from basal area

Checking the box next to the button opens the VR Crown Cover % Calculation dialogue box.   Enter the basal area (m2/ha) of the retained trees and click OK.

NOTE:  This calculation is a function of species, top height, and the proportion of dispersed vs. aggregated retention.  The calculation is automatically updated when any of these values are changed.

Incorporate windthrow into VR calculations

Check this box to have TIPSY modify VR calculations based on predicted windthrow associated with VR harvesting.   Checking the box opens the Windthrow dialogue box to configure the Windthrow model.  NOTE:  This option is only available with certain combinations of VR inputs.  E.g., when using the Formula method (below), retention must be entirely (100%) aggregated or dispersed.   TIPSY will alert you to these limitations.

Determine edge length by

Inputs depend on the method selected (below).   For multiple-species, the leading species is used to calculate edge length, which is then pro-rated accordingly.

Formula method (default)

Specify the retention patterns present, Aggregate groups vs. Dispersed trees, as a proportion (%) of the retained crown cover, or basal area, depending on how Crown cover (CC) retained (%) has been specified above.   TIPSY forces the sum (aggregate +  dispersed) to equal 100%.

Also specify the Average group size (m2) for Aggregate groups, and Average crown area (m2) for Dispersed trees.

Calculated edge length will update automatically as all these values change.  See Variable Retention: Models for more about the formulas TIPSY uses for this calculation.

User Specified method

TIPSY also allows direct entry of edge length (perimeter, m/ha).   This could be estimated from GIS mapping of the VR block layout.   Alternatively, GIS could provide the average size of the groups/trees for use in the Formula method above.

Geometry method

TIPSY can also calculate edge length based on simple geometry.   This requires an estimate of Average group size (m2) and a representative Group shape.   For 100% individual tree (dispersed) retention, Average group size represents average crown area per tree.

Group shapes include:  circular, square, rectangle (form factors 1x1 to 1x9), and irregular (equal to a 1x12 rectangle).

With Crown cover retained (%), Average group size, and Group shape, TIPSY is able to calculate the number of groups per ha, which it then uses to calculate edge length per ha.

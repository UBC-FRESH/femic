Curve Specifications

The Curve Specifications dialog box is used to select a different site index curve from the drop-down list of citations. The citation preceded by an asterisk (*) is the ministry-recommended site curve.

The Notes button displays more information about the selected curve.

The Use Ministry Standard Curve button resets the selection to the ministry-recommended site curve.

The suite of site index curves in TIPSY resides in the accompanying SINDEX.DLL file.   This same DLL is also used in SITETOOLS and can be downloaded for incorporation in other programs.

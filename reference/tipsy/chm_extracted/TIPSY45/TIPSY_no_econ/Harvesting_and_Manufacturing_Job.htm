The default values reported above are in person years per 1000 cubic metres harvested (PY/1000 m3). For simplicity, TIPSY converts these values to person days per 1000 m3 using the following formulation:

PD/1000 m3 = PY/1000 m3 x 200 days

where:

200 days represents the number of working days per year.

TIPSY then translates PD/1000 m³ to PD/ha as follows:

JOBS(PD/ha) = JOBS(PD/1000 m³) * Merchantable volume(m³/ha 12.5+) / 1000

This is so that TIPSY can display all jobs in the same units in its output, including the total number of jobs. To better understand these calculations, see Jobs Table Detailed Example.

Source:

The default harvesting and manufacturing jobs represent fifteen-year averages (1977 to 1992) data from Employment Canada, Statistics Canada and Census of Manufacturers, reported by Resource Tenures and Engineering Branch (formerly Timber Harvesting Branch).

Comments:

  • Job requirements for commercial thinning are assumed to be 15% higher than the jobs needed for the final harvest because of the smaller piece size.

  • Harvesting and manufacturing jobs are calculated at each TIPSY age (years since disturbance) requested in the Table Specifications dialog box.

  • The combined OAF, if less than 1.0, will affect merchantable volume and job requirements.

See also Commercial Thinning and Commercial Thinning Costs.

Input species variables, Batch

In this dialog box, you specify the column numbers in your input data file for all species related information, including:

  • Each species in your input file. Once you have entered start and end column numbers for one species, another field becomes available. The first species doesn't need to be the leading species. You'll have a chance to change site index curve and volume curve mappings later. Only five species are possible.

  • Percent Composition: for each species in the stand, if more than one species.

  • Genetic worth information for planted stock consists of expected Gain (%) and Index Age. The default is zero percent gain.  See Genetic Gain in TIPSY for more information.

  • Custom Stock Height. If you don't enter a custom stock height, TIPSY uses the defaults listed in Planting Stock Height. These defaults are for the height of one-year old stock grown in the nursery. See Implementing Size of Planting Stock for more information on this.

  • Site index. You must specify a site index for the leading species. If you have only one site index, but more than one species, BatchTIPSY will calculate the unspecified site index using the known site index, using site index conversion equations. If conversion equations don't exist between those species, then it just uses the site index of the leading species. See Site Index Conversion for more information.

BatchTIPSY will also calculate site index using Height and Total Age. If the total age is less than 30, BatchTIPSY automatically uses Site Index Class to determine site index. Use G, M, P, and L for good, medium, poor and low classes, respectively. BatchTIPSY will automatically convert these site class the measure of the relative productive capacity of a site for a particular crop or stand, generally based on tree height at a given age and expressed as either good, medium, poor or low values to site index values using site class conversion table. Otherwise, site index is calculated using the height and total age.

  • Fertilization Response.  Unless Use custom response data is checked, the Ministry default response models will be applied to all species.

When Use custom response data is checked, BatchTIPSY looks for a Custom Fertilization Response file and reads two columns in the input file to determine how custom responses are applied to each species:

Custom response data column:  U = apply custom response from file
                                               blank or any character except U = apply ministry default

Response type column:   A = apply absolute response
                                      blank or any character except A = apply percent response (default)

You can also input species-specific coefficients for snags and coarse woody debris, but these options are available from the Edit menu only, whenever a batch file is open. All species are listed.

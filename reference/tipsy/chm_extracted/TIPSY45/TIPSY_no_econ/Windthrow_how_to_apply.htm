Windthrow: How to apply in TIPSY/BatchTIPSY

Interactive

To apply windthrow to variable retention calculations, click on the “Incorporate Windthrow into VR calculations” checkbox from the Variable Retention dialog.

TIPSY calculates the Crown Cover Loss Factor (CCWT) and displays it on the Windthrow dialog for a selected location model (Mitchell et. al 2001; Lanquaye and Mitchell, 2005).  You can also see the combined effect of windthrow and variable retention at the bottom right of the dialog.  As you make changes in this dialog, the values are automatically recalculated.  You can also select the Default button at any time to see the default values for your selected location model.  If you make changes to variable retention while windthrow is in effect (for example, changing the retained crown cover %), TIPSY automatically updates the windthrow calculations.

You can choose “User Specified” as the location model and enter the CCWT directly instead of having the model calculate it.  See How TIPSY applies Windthrow for more information on how CCWT is used.  The effect of windthrow isn't displayed on the variable retention dialog.  It is displayed in the windthrow dialog and in the stand description.

The windthrow model works with certain combinations of variable retention inputs only.  For example, you can't use windthrow with the formula method of edge length determination and a crown area that is partly aggregated and partly dispersed.  TIPSY will alert you to these limitations.

Some effects of windthrow, such as reducing the plantable area, are not currently available.

The windthrow model is not species specific.

BatchTIPSY

To use the windthrow module, check the “Incorporate windthrow into VR calculations” checkbox from BatchTIPSY's variable retention dialog.  In the windthrow dialog, enter the input file location for the model and seven related windthrow inputs.  For more information on available ranges for the inputs, see below.

Notice that the first input after Model can be used for either the Bearing or CCWT.  BatchTIPSY will decide how to interpret values in the data file depending on the model specified.  If the model is ‘User Specified’, the program will interpret it as CCWT.  Otherwise, it will interpret it as Bearing.  Be sure to leave enough room in your input file for CCWT values (which can be longer than the Bearing values).

BatchTIPSY operation

If all windthrow inputs are missing/blank, then the program will continue with no warnings or errors, and will simply not apply windthrow to that particular table.  If some, but not all, windthrow data is present, an error will be produced and the table will not be run.  The one exception is if you’ve selected “User Specified” as a model.  In that case, only the CCWT input is needed.

The location model is specified as a single letter in the input file, as follows:

M: Canfor's McGregor TFL

N: Weyerhaeuser's North Island (Sayward /Tsitika /Eve River; NIT) operating area

Q: Weyerhaeuser's Queen Charlotte (QCI) operating area

T: Tembec's Golden TFL

W: Weyerhaeuser's West Island (Port Alberni; WIT) operating area

L: A portion of Slocan's Slocan Valley Forest License (Lemon)

C: Coast (pooled coastal model)

I: Interior (pooled interior model)

P: Province (pooled provincial model)

U: User Specified

Any other letter will generate an error.

Keep in mind the available data ranges.  If an input column contains data beyond the available range, BatchTIPSY produces an error message and won’t run that row of the table.  Also, BatchTIPSY checks to see if  the “formula” method of variable retention calculation is used with partially aggregated and dispersed retention.  If so, windthrow inputs will produce an error message due to limitations of the windthrow model.

The windthrow model works only with certain combinations of variable retention inputs.  For example, you can't use windthrow with the formula method of edge length determination and a crown area that is partly aggregated and partly dispersed.  TIPSY will alert you to these limitations.  BatchTIPSY produces an error message in its .err file.

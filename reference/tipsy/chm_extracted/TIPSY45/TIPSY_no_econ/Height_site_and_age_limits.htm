Height, site and age limits

The table below summarizes Top Height, site index, and age limits within TIPSY's database.  If user inputs exceed these limits, TIPSY output tables display the message "User requests exceeded database limits".

Output Tables based on height, as opposed to age, cannot reach the maximum top height if constrained by site index and age. For example, coastal Douglas-fir (Fdc) will attain a height of 60 m on site 35, but not on site 30.

To maintain consistency with VDYP, BatchTIPSY will report yield data to age 350.  However, yields will "flatline" past the limits of TIPSY's database.

Timber Supply Format Table

The Timber Supply Format Table is designed to mimic Batch VDYP output.

There are 3 columns in a Timber Supply Format table:

  1. Disturbance Age (aka TIPSY Age). See Ages in TIPSY for more information.

  2. One (only) type of volume selected from the Merchantability Limits dialogue box.   See VDYP Format Table for a comparison of VDYP and TIPSY volume types.

  3. DBHg

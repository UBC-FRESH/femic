How to Use TIPSY Help

Get Help on commands or open dialog boxes

With a dialog box open, or a table highlighted, press F1 or select the Help button to get Help on that particular table or dialogue box. This is called context-sensitive Help.  It is usually the quickest way to solve a problem or answer a specific question.

Help Topics

Select Help Topics from the Help menu. Then select one of three methods to find the information you need.

  • The Contents tab contains a series of books/folders organized by subject matter like chapters in printed documentation. You can browse the Table of Contents for the information you want to view.

  • The Index tab provides links to topics via keywords.

  • The Search tab allows you to perform a full-text search.  A list of topics appears that contain the search word.   The search word will be highlighted in each topic.

Note that although TIPSY has an imperial measurements option, all documentation, including the Help, uses metric references and examples.

Jumping to other topics and web sites in Help

Through text links

Topics in Help are often linked to other related topics. Links appear as underlined blue text. Selecting the Back button takes you back to where you were. Website links are displayed the same way. If you select one of these links, your web browser starts automatically in your Help window and you can view the website from there. Again, use the Back button to return to the previous topic or the Forward button to retrace your path in the opposite direction.

See also button

This button may also be labeled the Related topics button.  It provides links to topics that discuss other aspects of the same TIPSY feature.

Of course, if you are still stuck, contact User Support.

Stand Description Display

The Stand Description Output Table is accessed  through the Tables Menu or the Tool Bar icon above.   This table provides a summary of species, stand, and treatment information for the current stand. It contains all the information needed to recreate the regime in TIPSY.    This same information also appears at the top of printed output tables, as a reference.   However, it cannot be printed by itself.   To print output tables without this information at the top, use the Export option in the File Menu.

The Stand Description Display dialogue box is accessed through the Edit Menu or the Pencil icon on the Toolbar.  This dialogue box controls the level of detail reported in the Stand Description Output Table.

Combined Operational Yield Adjustment at 100 years is based on TIPSY age.  If you were to calculate this adjustment manually using the individual OAFs at age 100 (which are based on germination age), the numbers may not be the same.

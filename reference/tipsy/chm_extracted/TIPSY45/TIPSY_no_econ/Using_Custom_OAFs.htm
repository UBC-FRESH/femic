Introduction

Customs OAFs can augment or replace OAF1 and OAF2.   Species-specific Custom OAFs are applied in Species Specifications, while Stand-level Custom OAFs are applied in Stand Specifications.   Custom OAFs can be applied in BatchTIPSY, as well.

Custom OAFs enable the creation and application of OAFs for specific yield impacts ( e.g., specific insects and diseases) in ways that are not possible with regular OAFs (1 & 2) alone.   The design of Custom OAFs normally requires the involvement of subject specialists (e.g., entomologists, pathologists, etc).   For example, TIPSY includes Custom OAFs for Armillaria root-rot (ICH Douglas-fir only) that were developed in cooperation with pathologists from the Canadian Forest Service.

Custom OAFs reflect impacts on Merch. Volume (12.5+).

NOTE:   The combined effect of all OAFs is additive.  Therefore, whenever OAFs are added or modified, all existing OAFs must be re-evaluated and modified (or turned off) in context.

Custom OAFs affect yields in much the same way as regular OAFs (1 & 2) with the exception of gross volume volume of all living, dead and thinned trees (total production) [m3/ha]. See Impacts of Adjustment Factors for details.

Custom OAFs Intensity dialogue box

Both Species-specific Custom OAFs and Stand-level Custom OAFs are defined and activated through the Custom OAFs Intensity dialogue box, and two other dialogue boxes nested within it.   TIPSY comes with three pre-defined Custom OAFs.   The two Examples (1 & 2) have been configured to mimic OAF1 and OAF2 for demonstration purposes.

The Custom OAFs Intensity dialogue box lists existing Custom OAFs definitions available for use.   Each line contains four radio buttons enabling selection of intensity (severity) levels specific to each Custom OAF definition.   Selecting "None" deactivates the Custom OAF.   See below for more detail.

Additional Custom OAFs can be added or edited by clicking the Add/Edit Custom OAFs button at the bottom to open the Customs OAF Specifications dialogue box.

TIPSY also provides pre-defined Custom OAFs in conjunction with certain species, i.e.:

For interior Douglas-fir (Fdi) in the ICH BEC Zone only, a pre-defined Armillaria Custom OAF appears, which is disabled by default.

For aspen (At) and alder (Dr), an pre-defined Age Decline Custom OAF is applied to these two species by default, to better reflect the behavior of these shorter-lived broadleaf species.  It can also be manually disabled in this dialogue box.

Customs OAF Specifications dialogue box

The Custom OAF Specifications dialogue box enables creation and editing of Custom OAF of definitions, also referred to as Response models.  It is accessed through the Custom OAFs Intensity dialogue box (above).

The Custom OAF Specifications dialogue box contains:

  • Name box:   Selects and displays an existing Custom OAF for editing, or renaming.

  • Add a new OAF button:  Begins a new OAF definition by inserting a temporary name into the Name box.   This name can be edited.

  • Delete current OAF button:  Deletes the OAF definition displayed in the Name box.

  • In relation to Age or Height:  selects the variable anchoring the Response model.   Selection will depend on whether an impact is best described as a function of stand age or top height (tree size).   Like all other OAFs,  age refers to Germination Age.

  • Move trees... or Remove trees...:  Normally, the first option (Move...) is preferred.  This moves dead trees to the Mortality Table where they become Snags and eventually CWD.   I.e., dead trees remain in the stand.  The second option removes dead trees from the stand, e.g., sanitation or salvage operations.

  • Response:  This box displays the Response model definition.   Each column defines the OAF effect at a specified age or height, for each intensity (severity) level, i.e., none (fixed at 1.00), low, medium, high.

  • Add, Edit, Delete buttons:   Operate on the individual columns of the Response model.   Edit and Delete operate on the selected (highlighted) column.   Add and Edit open the Custom OAF Response dialogue box (below).

    TIPSY allows a maximum of 5 columns.  TIPSY adheres to the following rules:

    • Rule 1. OAF values represent the impact on Merch. Volume (12.5+).

    • Rule 2. By default, the first OAF in a sequence is 1.00 at age zero, unless specified otherwise.

    • Rule 3. The OAF value remains constant (to age 300) after the last specified value.

    • Rule 4. TIPSY uses linear interpolation to provide OAF values for intermediate age or height steps.

See Custom OAFs Development for examples.

Custom OAF Response dialogue box

The Custom OAF Response dialogue box is used to define each intensity (severity) level within one column of the Response model displayed in the Custom OAF Specifications dialogue box (above).   The top line defines age (or height) for the column.   The remaining lines define the OAF value (yield multiplier) for each of the intensity (severity) levels, i.e., none (fixed at 1.00), low, medium, high.

NOTE:   As with regular OAFs (1 & 2), individual OAF values may be greater than 1.00, but the combined (net) effect of all OAFs combined cannot increase yield.   Therefore, TIPSY caps the annual net effect at 1.00.  A message appears when this occurs.

How Custom OAFs work

TIPSY derives annualized OAF values via linear interpolation between the OAF values specified in the columns of the Response model displayed in the Custom OAF Specifications dialogue box (above).   Each Custom OAF definition contains 4 separate response models, one for each of the intensity (severity) levels, i.e., none (fixed at 1.00), low, medium, high.   Examine the two OAF definitions (Example 1 & 2) included with TIPSY:

Example 1 is configured to mimic the default OAF1 (0.85).   Since OAF1 is a constant multiplier, only one age (or height) column is required.   Furthermore, this particular OAF must be defined at age zero in order for TIPSY to apply it over the entire rotation.

In Example 2, the low intensity (severity) model is configured to mimic OAF2.   The definition uses three columns.  The first column initializes the OAF at 1.00, at age zero.   The second column (age 100) defines the default OAF2, i.e., 0.95 at age 100.   The third column (age 300) extends the OAF2 effect out to age 300, the practical limit of TIPSY.   Without this third column, the OAF would stop decreasing past age 100 and remain static at 0.95 thereafter.   Note, the second column (age 100) values are not actually needed to define this simple linear OAF model.

Additional columns (ages or heights) enable more complex (segmented linear) OAF models to be defined.   However, TIPSY uses linear interpolation between these points.

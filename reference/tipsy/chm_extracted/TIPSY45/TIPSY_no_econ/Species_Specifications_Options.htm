OAFs (species-specific)

This is one of four main dialogue boxes used to edit the settings required to generate output tables for a unique stand.   It is accessed through the main Edit Menu and the icon on the Tool Bar.

The table at the top lists the species (rows) and their properties (columns) that are currently selected for the stand.    

Buttons across the bottom open separate dialogue (settings) boxes for each species property (column) in the table.

TIP:  Individual values in each column can also be edited by double-clicking on them.

Species

Species Selection is managed with the Add and Delete buttons in the lower right corner.

 

Percent Composition

Percent Composition (%) for each species is edited in the Percent Composition dialogue (settings) box.  The box appears each time an additional species is added to the table to define a multi-species stand.   Yields for multiple species stands are pro-rated.  The button is inactive (greyed out) when only one species is selected.

Stock Height (cm)

Stock height of planted stock is edited in the Planting Stock Height dialogue box.   The initial value displayed is the species-specific default for "1+0" stock; it can be overwritten if the actual value is known. The button is only active (not greyed out) when Planted has been selected in Stand Specifications.

Genetic Worth (%)

Optionally, species-specific genetic worth can be assigned to planted stock (only) by checking the box next to the Genetic Worth (%) button.  This opens the Genetic Worth dialogue box to view default values or edit them.  Both check box and button are only active (not greyed out) when Planted has been selected in Stand Specifications.

Fertilization Response

This button opens the Fertilization Custom Responses dialogue box which provides options for specifying custom response models, or using TIPSY's built-in Ministry default models.   Fertilization treatments are scheduled through the Fertilization treatment settings in Stand Specifications.

Return to Top

OAFs (species-specific)

Optional species-specific custom OAFs (Operational Adjustment Factors) can be assigned by checking the box next to the OAFs (species-specific) button.  This opens the Custom OAFs Intensity dialogue box to configure custom OAFs for the species.  Unchecking the box disables these OAFs, but retains the current custom OAF settings.

To better reflect the behavior of shorter-lived broadleaf species (aspen and alder), an Age Decline custom OAF is applied to these two species by default.  

TIPSY's OAFs for Armillaria root-rot (ICH Douglas-fir only) are also implemented as custom OAF.

WARNING:   The combined effect of all OAFs is additive.  Therefore, whenever OAFs are added or modified, all existing OAFs must be re-evaluated and modified (or turned off), in context.

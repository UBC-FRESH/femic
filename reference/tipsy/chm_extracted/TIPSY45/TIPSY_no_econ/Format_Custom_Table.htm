Custom Output Description, Batch

This option is available only if you have selected the custom table option in BatchTIPSY. Here you can select the content and location of the information that appears at the top of each table in your output, similar to the Stand Description in TIPSY. Most values are just copied from your input file.

  • Include table separators inserts a dashed line at the end of each table.

  • Include column headers refers to a primary level of heading for each column in the tables.

  • Include spanned headers refers to a higher level of spanned header for the columns in the tables.

  • Location of table description lets you choose to display the stand description either at the top of each table, as in TIPSY, or in columns down the left hand side of the table. With the left hand column option, each item of stand information occupies a column. The column just repeats the stand information for every row of the table.

You might notice that when the stand information is displayed in the [left-hand] columns, there isn't as much detail. For example, the combined OAF value isn't displayed, only OAF 1 and OAF 2. This is just to save space. To see as much information as possible, select the Above the table option.

  • Table description details just copies your input to the output.

- Record # is just a number that BatchTIPSY assigns to your output

- Table ID is an ID number that you create or enter in your input data file.

  • Stand information options include:

- Summary or Details - an option to display all of the same information abbreviated.

- Initial density

- Regen. type

- Regen delay

- Treatments include pre-commercial thinning, commercial thinning and fertilization.

- OAFs include the combined OAF value.

- Area is the number of hectares that the stand occupies.

  • Species Information options include:

- Site curve (source) information

- Top height @ bh age 50

- Planting stock height

- Genetic worth values

- Fertilization response

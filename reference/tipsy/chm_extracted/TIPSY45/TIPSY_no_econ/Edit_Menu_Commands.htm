Edit Menu Commands (Alt + E)

Edit menu commands allow you to access and edit stand and table specifications.   The list of menu commands is context sensitive, i.e., only commands relevant to the table displayed in the active (highlighted) window are shown.  E.g., the Jobs... command is only shown when the active window displays a Jobs table.

The Edit icon is used to edit settings for the Output Table displayed in the active (highlighted) window.

A subset of the following commands will appear in the Edit Menu, depending on the context.   Click the links below to explore each one.

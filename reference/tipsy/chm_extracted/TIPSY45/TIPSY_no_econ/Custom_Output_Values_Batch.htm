Custom Output Values, Batch

If you select the custom table option, the Custom Output Values dialog box lets you organize the contents and appearance of your output, column by column. You can choose from all variables currently available for output in BatchTIPSY. Some variables are available only through the custom table, such as dead wood information.

The Sets of Variables options is just a way of short-listing a long list of 'All' variables.

Once you have chosen the variables, use the Up and Down buttons to rearrange them. You have to highlight each variable individually.

Merchantability Limits

The Merchantability Limits settings box is used to select the various stand volumes reported in Timber Supply, VDYP, and Yield/MAI tables.  The Merchantability Limits settings box opens the first time a particular table is accessed.   Subsequently, these settings can be accessed with the Edit menu or the Pencil icon on the Toolbar.

This dialogue box lists nine options; the first eight have pre-defined DBH limits that exclude trees below the specified minimum DBH.

Total Standing 0.0+ and 7.5+:
whole stem volumes, with no deductions for tops and stumps.

Merchantable 7.5+, 12.5+, 17.5+, 22.5+, 27.5+, and 32.5+:
merchantable volumes, less 10 cm tops and 30 cm stumps.

Other Utilization:
user-defined minimum DBH.  TIPSY can interpolate between the two Total Standing volumes (0.0+ and 7.5+) or the last five Merchantable volumes (12.5+ to 32.5+).  However, TIPSY cannot extrapolate outside these two ranges.   I.e., entering a value between 0.0 and 7.5 interpolates Total Standing volume.  Entering a value between 12.5 and 32.5 interpolates Merchantable volume.   Interpolation of Merchantable volume between 7.5 and 12.5 is not possible at this time.

The number of volume options that can be selected depends on the type of table:

  • Yield Table - one to eight.

  • VDYP Format Table - two (only) are required.

  • Timber Supply Format Table - one (only) is required.

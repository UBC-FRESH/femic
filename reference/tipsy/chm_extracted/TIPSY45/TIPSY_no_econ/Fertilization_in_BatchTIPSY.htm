Fertilizer Applications, Batch

Link to Input File Format

The Fertilzer Applications form appears when Fertilization has been selected in the Input Variables dialog box.

Enter the Input File column numbers defining up to five ages at which fertilizer is to be applied.

Unless Use Custom Response Data was previously checked on Input Species Variables form, the  ministry standard response defaults will be applied to all species.

Check the Specify custom effectiveness box to read custom effectiveness values from the input file.  Otherwise, the default of 80% will be applied.

The response is also automatically reduced further (x 0.75) to compensate for competition (under- or over-stocked stands) if the:

  • Crown cover is < 30% (low stocking adjustment) or

  • Live crown ratio of prime trees is < 40% (intense competition adjustment)

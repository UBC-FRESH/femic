Output data file, Batch

The Output Data File dialog box lets you name your new output data file, the file that is the result of the batch processing. This file appears on your screen when you open a batch processing (.btp) file.

Use the browse feature to view other file names or to change directories. You may notice that you can't enter the file name into the box where it's displayed. The Browse button opens a standard MS Windows file dialog box, which checks for overwritten files, etc.

We have suggested .out as the file name extension. A file called batcheg.out is distributed with the program.

If TIPSY encounters a problem while processing data, it will also output an error file and give you the directory location. The example files that we've included with the program generate an error file, simply for educational purposes.

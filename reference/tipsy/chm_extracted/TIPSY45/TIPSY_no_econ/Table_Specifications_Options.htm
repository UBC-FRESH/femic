Table Specifications

This is one of four main dialogue boxes used to edit the settings required to generating output tables for a unique stand.   It is accessed through the main Edit Menu; it has no Tool Bar icon.

Table Specifications control the basic display format of Output Tables.  Settings are divided (boxed) into two (2) groups:

In Relation to

Select Age (TIPSY Age) or Top Height  as the main reporting variable defining each table row.   Top Height reporting is only available for single-species stands.

This selection also becomes the X-axis variable when plotting with Plotsy.

Ranging

Ranging refers to the reporting variable selected above, i.e., Age (TIPSY Age) or Top Height

From specifies the first row of a table, To specifies the last row, and In steps of specifies the reporting interval.   

Units are years and metres/feet for Age (TIPSY Age) and Top Height, respectively.

Tables are automatically truncated whenever they reach the upper limits of TIPSY's database.

MAI is always calculated using one-year steps regardless.

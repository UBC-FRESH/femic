CWD Volume Decay Function dialog box

When a CWD Output Table is requested, the CWD Volume Decay Function dialogue box appears first.  Subsequently, it can be accessed using the Edit Menu (CWD...) or the Pencil icon on the Toolbar.

The CWD Volume Decay Function dialog box lets users change the decay rate associated with each species (see CWD Model) in your stand. To change the coefficient, select the appropriate species in the Species Coefficient list and then overwrite the value in the box labelled k. To return to the default value of a species, select the species, then click on Use Defaults for this Species.

The effect of the k value on CWD volume can be explored with the Example box.   Enter an initial (old) volume and a time interval then click New Volume? to make the calculation.

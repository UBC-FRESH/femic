CWD Table

The CWD (downed coarse woody debris) Output Table is accessed through the Tables Menu or the Tool Bar icon above.  Reporting of CWD is controlled through two dialogue boxes:

The CWD Volume Decay Function dialogue box appears first when a CWD Table is requested.   Subsequently, this dialogue box can be accessed with the Pencil Icon in the Toolbar.   The recommended default settings for the selected species are displayed.  Users can also modify the functions based on their own data.

The Coarse Woody Debris Table Options dialogue box  appears next, enabling selection of periodic or cumulative reporting options.  Clicking the CWD table icon on the Toolbar always opens a new table, rather than modifying the existing CWD Table.

Note, TIPSY assumes no CWD from previous stands remains on the forest floor at stand establishment.

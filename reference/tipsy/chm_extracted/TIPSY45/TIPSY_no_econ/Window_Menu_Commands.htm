Window Menu Commands (Alt + W)

Cascade

This command arranges all open windows stacked on top of each other, so that the bar at the top of the window where the file name appears is displayed for each open window. The active window, ie. the one that you can edit or plot, is the one with the highlighted title bar at the top. You can change the active window by highlighting a different title bar.

Tile Horizontal and Tile Vertical

The Tile command arranges all open windows to fit your screen. Experiment with the Horizontal and Vertical commands to find your preferences. Again, the window with the highlighted bar is the active one, i.e. the one that you can edit or plot.

Arrange Icons

Use this feature if you have minimized and moved a number of TIPSY windows, and you want to align the icons.

Collapse Views

If you have many windows open, and want to keep only the current highlighted one open, use this command. It will act only on the file that is in the window. This is similar to using Preferences, except that your selection doesn't get saved.

Close All Views

This command closes all files/views at once.

You'll also see a list of all open windows in the Window menu.

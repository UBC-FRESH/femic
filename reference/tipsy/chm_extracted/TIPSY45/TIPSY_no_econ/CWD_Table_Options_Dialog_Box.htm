When a CWD Output Table is requested, the CWD Volume Decay Function dialogue box appears first.  This is followed by the CWD Table Options dialogue box, which can be re-accessed later by clicking the CWD table icon on the Toolbar.

The CWD Table Options dialogue box provides two general reporting options that each have two options, as described below.  Text at the bottom of the dialogue box briefly explains each option, when selected.

Note, TIPSY assumes no CWD from previous stands remains on the forest floor at stand establishment.

Periodic Recruitment Options

The Report CWD Periodic Recruitment option contains options for reporting periodic recruitment as Number of Trees or Volume.

Specify recruitment age option

The Specify recruitment age option displays only CWD recruited between the specified From and To years, prior to each age reported in the table.  Table age steps are set in Table Specifications.

For example, if you enter a From of 0 and a To of 20 years, and your tables have age steps of 5 years, then up until age 20 all trees that became CWD (less decay) are included in each row of the table; but after age 25 only trees that became CWD (less decay) in the previous 20 years are included in each row. From this you might infer 'decay classification' information (i.e., how rotten a log might be).

Below is an example of a CWD Table with the 'age' of the CWD listed added in the left hand column. It uses the same example of CWD that is 0 to 20 years 'old'.   This example was created with a previous version of TIPSY.

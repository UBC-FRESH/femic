Input data file, Batch

The Input Data File dialog box lets you:

  • select the data file that you want to process. Use the browse feature to view available files, change directories, and select the input file. We have included the file Batchin.dat with the program. You can't actually enter the file name in the box where it's displayed.

  • view the input data file. Use the scroll bars along the right or bottom to view more rows and columns of data. You may not be able to see all of the file in the viewer.

  • specify lines, or rows, to skip at the top of the file. You may find this convenient if the file contains column headings or titles.

Tips

  • If there are blank rows in the input file, BatchTIPSY ignores them.

  • If your input file looks different in another program than in BatchTIPSY's viewer, then you may need to change the delimiters in the input file. Make sure that there are only spaces, and not tabs, between the columns of data in your input file.

  • If BatchTIPSY can't process every row in the input file, it will generate an error file and display the folder location. The example input file that we've included with the program generates an error file for educational purposes.

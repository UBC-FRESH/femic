Timber Supply Format Table, Batch

There are three columns in each Timber Supply Format table:

  • Age since disturbance (TIPSY age). See Ages Defined in TIPSY for more information.

  • Merchantable volume. If your input file doesn't contain utilization limits, Batch TIPSY defaults to 12.5+.

  • DBHg

The Timber Supply Format table is a pared down table, designed to save disk space and also mimic Batch VDYP output. Once you have eliminated the processing errors and are satisfied with your BatchTIPSY runs, you might choose to save your final output in this format.

The column headers are intentionally misaligned with the text. (The reason for this is no longer clear!)

The Custom table in BatchTIPSY allows more flexibility.

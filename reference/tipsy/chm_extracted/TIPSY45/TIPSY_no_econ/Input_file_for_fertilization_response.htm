Fertilization: Input File Format

The same basic Custom Fertilization Response File format applies to both Interactive and Batch TIPSY.   Response files must first be imported through the Edit Menu before this option can be used in Interactive TIPSY.

A Fertilization Response File is a CSV text file with the following format:

Line 1:   Interactive TIPSY always skips this line.   It can be used for descriptive text (comments).   Batch TIPSY expects data in line 1, unless told otherwise.

Line 2+:  species code, site index, age, % response, absolute response (m3, optional)
             – comma delimited required

Example:      SW, 20, 0, 0, 0

SW, 20, 17.5, 25, 4

: : :

SW, 20, 98.9, 29, 10

SW, 20, 141.7, 0, 0

SW, 20, 400, 0, 0

Responses will automatically be capped at 200% of the species default.   When errors are encountered, the file is rejected and Ministry defaults are used.

NOTE:  absolute response models only apply to one specific initial density.  For ministry default models, this is 1100 stems per ha.  For custom user-defined models, this density is determined by the model creator.  Model creators are encouraged to document this density in the Line 1 comments for the benefit of other users.   

Contact TIPSY User Support for more information.

Output Table Format, Batch

There are 5 options for Output Format:

  1. Standard BatchTIPSY

  2. Timber Supply

  3. Custom

  4. Transposed lists all ages or heights on a single row, in TAB or CSV format.

  5. By Species reports volumes by species and utilization level, in TAB or CSV format.

Standard BatchTIPSY and Timber Supply tables are pre-formatted for certain applications. The Custom table provides more flexibility.

BatchTIPSY output includes data to age 350, which is beyond the limits of TIPSY's database. This maintains consistency with other programs such as VDYP. However, output values remain static after TIPSY reaches the database limit of the leading species.

See Height, site and age limits for more information.

Output Errors option creates an error log. BatchTIPSY writes the error log to the same location as your batch file, with a similar file name. You can't open it in BatchTIPSY. Notepad works well, but any text editor will do.

Regime Files option creates .RGM files for use in FAN$IER.

Woodlot Files option creates .WLT files for use in Woodlot (timber supply analysis app for BC Woodlot tenures)

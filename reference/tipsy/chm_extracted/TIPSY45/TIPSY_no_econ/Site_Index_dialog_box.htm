Site Index

TIPSY provides an initial site index value, which can be overridden manually if a better estimate is available.  The initial value displayed by TIPSY is context sensitive:

1) for single species stands, the current TIPSY default for the species is displayed.  This first species is also automatically labelled the reference species in case additional species are added to create a multi-species stand.

2) if and when additional species are added, TIPSY uses built-in Site Index Conversion equations to automatically predict the Site index (SI) a measure of site productivity based on the top height [meters] of a stand at breast-heightage 50. Override SI Conversions

Check the Override any site index conversions box to maintain (lock in) the manual override described above.   However, if the species is later designated as the reference species, this override lock is released.

Calculate from Age & Height

Click the Calculate from Age and Height button to open the Age/Height calculator, if you wish to calculate site index from an age and height data.

Summary box

The Summary box displays the effects of height repression being applied to overly-dense lodgepole pine.   PCT can avoid these effects.

Curve

The Curve button displays the citation for the species-specific site index equation currently being used by TIPSY.   An asterisk (*) indicates the ministry-recommended curve for a particular species.

Clicking the button opens the Curve Specifications dialogue box.

Related Info

To view the species-specific site index ranges that are supported by TIPSY, see Height, site and age limits.

When the site index difference between any two species exceeds 5m, a warning message appears on-screen and on printed output. This is to alert users to the limitations of the multiple species feature.   See Pro-rating Multiple Species.

Yield Table

The Yield Table is accessed through the Tables Menu or the Tool Bar icon above.  This table reports a common set of yield table variables.   Reported volumes are selected with the Merchantability Limits dialogue box.

Yield Table output provides quick access to common variables, but Custom Table output has greater reporting flexibility.

Variable Retention: Interactive

Interactive TIPSY

TIPSY needs three pieces of information about the retained groups:

1. total edge length

2. crown cover percentage (how much of the stand was actually retained as either aggregated groups or dispersed trees), and

3. top height at the time of variable retention (VR) harvest.

If, however, crown cover percentage or edge length is unavailable, TIPSY can calculate them using other stand values. Crown cover percentage can be calculated from the basal area of the retained groups. Edge length can be calculated using a formula provided by the Ministry (the default), or by geometry.

Enter this information via the Variable Retention dialog, accessible from the Stand Specifications dialog.

Calculating Crown Cover Percentage:

You can calculate crown cover percentage by basal area only if the edge length is calculated using the formula option. If crown cover is entered directly, it will be apportioned to the dispersed and aggregated edge length calculations accordingly. To calculate crown cover using basal area,

1. Select the checkbox near the greyed Calculate… button in the variable retention dialog.

2. Enter the basal area, then TIPSY converts it to a crown cover percentage for both types of retention.

TIPSY uses coefficients based not only on the species, but also on whether the calculation is for dispersed or aggregated crown cover percentage. TIPSY displays a single crown cover percentage, but uses the individual values to calculate the actual edge length. The single crown cover value displayed is also used in the calculation of the VR adjustment factor. Since the top height of the retained overstorey is used as part of the conversion formula from basal area to crown cover, the crown cover value is recalculated whenever the retained top height is changed. It will also be recalculated if you change the percentage breakdown of the retained groups.

If you choose to calculate crown cover percentage by basal area, the text on the Edge length section of the dialog will be updated to reflect this. Instead of breaking up the crown cover by aggregated and dispersed types, you are essentially breaking up basal area.

For a mixed-species stand, the leading species will be used to calculate edge length and pro-rated accordingly.

Calculating edge length using the Formula option (default option)

To use the formula calculation, you must indicate how much of the total retained stand is dispersed trees and how much is aggregated groups by assigning a percentage to both types of retention (these two percentages will always add up to 100%). For both types, you also need to specify the average size of the group area, and/or the average crown size of the dispersed trees. The calculated edge length will update automatically as these values change. The formula uses coefficients based on one of the four species.

Calculating edge length by the User Specify option

TIPSY allows you to directly enter the edge length (perimeter) per hectare retained. For instance, if a digitized aerial photo for the VR block layout is available, the total edge length of the retained groups can be calculated using imaging analyzing software. This will also provide the average size of the groups, which can be used as input in the Calculating Edge Length using the Formula option, described above.

Calculating edge length using the Geometry option

TIPSY requires an average group size as well as the general shape of the groups (circular, square, etc.) The "irregular" shape is modelled from a 12x1 rectangle. You can also have a rectangular shape of any dimension from 1x1 to 9x1. Based on this information and the value provided for crown cover percentage, the program can determine how many groups there are in all, and use that to calculate the edge length per ha.

For example, we want to remove 60% of the area of an existing 70-year old cutblock of coastal Douglas-fir (site index 30) located in Campbell River.  The cutblock prescription includes the retention of the remaining 40% of crown cover of the stand to meet VR objectives.  The retained area is aggregated into groups with an average area of 500 m2 and with a top height of 30m at the time of harvest.  

• If the user selects the “Formula” option, which was derived using a rectangular group shape (i.e. 2.5 x 1 rectangle group with an aspect ratio of 2.5), the calculated edge length per hectare is 1047.4 m/ha.

• If the user selects the “Geometry” and a “Circular” group shape option the calculation is done as follows:

Edge/ha = SQRT(group area / pi)    * 2 *  pi * CC% * 100 / 10000 * (# of groups/ha)

then

Edge/ha = SQRT(500 / pi)  * 2 * pi * 40 * 100 / 10000 * 20 = 634.1 m/ha

• If the user selects the “Geometry” and a “Square” group shape option the calculation is done as follows:

Edge/ha = SQRT(group area) * 4 * CC% * 100 / 10000 * (# of groups/ha)

then

Edge/ha = SQRT(500) * 4 * 40 * 100 / 10000 * 20 = 715.5 m/ha

• If the user selects the “Geometry” and a “Irregular” group shape option (i.e. 12 x 1 rectangle group with an aspect  ratio of 12) the calculation is done as follows:

 Side A length = SQRT(group area * 12)   * 2 = SQRT(500 * 12) * 2 = 154.9 m

Side B width = SQRT(group area / 12)   * 2 = SQRT(500 / 12) * 2 = 12.9 m

Edge/ha = (Side A + Side B) * CC% * 100 / 10000 * (# of groups/ha)

then

Edge/ha = (Side A + Side B) * 40 * 100 / 10000 * 20 = 1342.6 m/ha

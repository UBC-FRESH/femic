Moving the Toolbar

The row of icons below the Main Menu is called the Toolbar.  These icons function as short cuts for frequently used commands within the Main Menu.  Icons are grouped by function.

TIP:   Hovering the mouse pointer over each icon reveals its text label.

Moving the Toolbar

Using left mouse button, click on the vertical row of dots at the left end of the toolbar, then drag and drop it anywhere on your screen.  Dropping it near the edge of the application window docks it to the window edge, otherwise it floats where it is dropped.

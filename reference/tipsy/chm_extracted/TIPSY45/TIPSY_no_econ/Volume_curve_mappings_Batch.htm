Volume curve mappings, Batch

View Default Species Mappings here.

At the bottom of the TIPSY Volume Curve Mappings dialog box is a list of input species codes and FIZ The Forest Inventory Zone(s) that fall within the forest cover polygon. FIZ zones were developed to provide a broadly based ecological classification of the forestland in British Columbia. FIZ zones closely follow the early Biogeoclimatic zones developed by Dr. Krajina. The province of British Columbia is split into 12 FIZ zones. , with the corresponding database that BatchTIPSY uses.

If you have code/FIZ combinations that aren't listed, or that you want to overwrite, you can add your own mappings at the top of the dialog box. Just type the species code in the Input Code field, select a FIZ from the Input FIZ group and then select a volume curve from the drop-down list. Finally click the Add Mapping to Current List button and you will now see your species code and volume curve in the list.

Certain common species codes (such as FDC) have an assumed FIZ built right into the code (in this case, the “C” indicates “coastal”).  When users try to do BatchTIPSY runs without providing a FIZ for these particular species, the program generates a warning.  It was felt that for these species, this warning is not necessary, so we added a mapping for “None” (which will repress a warning if no FIZ is provided) for the following species input codes: CWC, CWI, FDC, FDI, HWC, HWI and PLI.

If you want to delete a current volume curve mapping, select it from the list, then a warning message appears asking if you want to delete both the volume mapping curve and the site index curve.

The Reset All to Default Mappings button resets both the volume and site index curve mappings to the ministry defaults (recommendations), regardless of which dialog box you are in.

BatchTIPSY uses the same volume curves (database) as TIPSY. If you are interested in knowing which version of TASS was used to create the database for each species in TIPSY/BatchTIPSY, read ''What's new in TIPSY'.

This paragraph is particularly relevant for Woodlot users. When using command-line arguments, the user has the option of specifying either a .btp file or the old DOS command line (input file, output file, format file, .dat files). Specifying a .btp file will be load it into the program as described above. If the old DOS command line is used, the mapping information in the .dat files will override any Ministry defaults.

Keep in mind that mappings are now saved in the .btp file, rather than the .ini file. BatchTIPSY used to save both site index and volume curve mappings in the .ini file. This created a personal set of defaults that appeared with each new .btp file, so you didn't have to reset them with each .btp file. Users found this confusing, if they ever realized it! Now the ministry recommended mappings apply to each new file, or document. Also, if you open a .btp file created with an earlier version of BatchTIPSY, the program will reset all site index and volume curve mappings to the ministry defaults.

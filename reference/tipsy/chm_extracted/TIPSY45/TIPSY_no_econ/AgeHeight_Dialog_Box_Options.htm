Lock Site Index (check box)

Within Existing Stand option

The Age/Height dialogue box is accessed from the Site Index dialogue box and Existing Stand Data dialogue boxes.   It serves as a calculator to estimate Site index from Top Height and Age, or any one from the other two.

The four age options are explained in Age Definitions.

The calculator opens in one of two "lock" modes, depending on TIPSY settings elsewhere:

Lock Site Index (check box)

Unchecked, the calculator functions as described above.  I.e., enter top height and age values to calculate site index, and automatically update (overwrite) the species' site index value.

This is checked (locked) automatically in situations where it is inappropriate to calculate site index from age and height data.  That is, in cases where site index, as reflected in top height, may be affected by other factors, e.g., genetic improvement, fertilization, or repression.  E.g., it is lock when using the Existing Stand Option with genetically improved trees.   In the locked state, the calculator can still be used to explore the relationship between age and height for stands of a particular site index.   I.e., change either one of the variables and the other will instantly change to maintain the same site index value.

Within Existing Stand option

The Age/Height dialogue box is also linked to the Existing Stand Data dialogue boxes.

Lock Site Index if Site Index is known and you wish to enter the existing (established) stand's density (trees/ha) and either top height or age (but not both).

Unlock Site Index if Site Index is unknown and you wish to enter the stand's density (trees/ha) and both top height and age.  In this case, TIPSY will re-calculate Site Index and update the main Site Index setting.

Site Index Conversion

Site Index Conversion equations are used in TIPSY for multiple-species stands to predict the Site Index of additional (target) species based on the site index of a reference species with a known site index.  The following table documents the equations currently in use by TIPSY.   These relationships were developed from, and should only be applied to, mixed-species, even-aged stands.

Each equation is of the form:   Target Species SI = a + b(Reference Species SI),
where a and b are the coefficients of the linear equation.   The equations are reversed algebraically to interchange target and reference species.

Export Table

The Export Table command in the File Menu saves the current Output Table as an ASCII text (.TXT) file that can then be imported into most other programs (word processors, spreadsheets, etc).

Select a Column Delimiter and the optional inclusion of Column Headers (column labels) and/or Stand Description information (preface text).

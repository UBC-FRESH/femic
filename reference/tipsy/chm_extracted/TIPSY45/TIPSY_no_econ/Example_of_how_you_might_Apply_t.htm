Estimate an initial density (with no PCT)

Estimate residual density after PCT

The following examples both assume a natural stand of lodgepole pine (SI 19), with a regen delay of 2 years, and no OAFs (1.0).  These examples were created with a previous version of TIPSY, so your outcomes may be slightly different.

Before using the Existing Stand Option, you must first define all relevant variables that affect the outcome of the Existing Stand Option. See Existing Stand Option: Introduction.

Start a new TIPSY project file and enter (edit) the following information:

Species Specifications:  species = 100% lodgepole pine; site index = 19m; select no other options.

Stand Specifications:  Stand Regeneration type = Natural;  Regen Delay = 2yrs; disregard Density for now;  OAF1 = 1.0; OAF2 = 1.0; select no other options.

Estimate an initial density (with no PCT)

This first example assumes the stand above has not be pre-commercially thinned.  At 19 years post-harvest (TIPSY Age), it has a known (measured) density of 7500 trees/ha.  In this case, TIPSY can estimate initial Density for you.

  1. In Stand Specifications, click the Density button to open the Initial Density dialogue box then click the Calculate from Existing Stand Data button to open the Existing Stand Data (before thinning) dialogue box.

  2. Enter the known density of 7500 trees/ha and then click the BH Age: ... button.   This opens the Age/Height dialogue box.

  3. Ensure the Lock Site Index box is checked.  This forces TIPSY to adjust the Top Height value to conform with the known site index and age values.

  4. Select the TIPSY Age option then enter 19 years then click OK to return to the Existing Stand Data (before thinning) dialogue box.

  5. Notice the information displayed on the BH Age: ... button has been updated with the new BH Age (11.0 yrs) and Top Height (5.5 m) values reflecting a site index of 19m.   Click OK to return to the Initial Density dialogue box, and notice the new estimated initial Density of 8521 trees/ha.

  6. Click OK to return to the Stand Specifications dialogue box, and click OK again to view the Stand Description display.   From here, you can open any of TIPSY's Output Tables to examine various yields.   Do not close this example if you are going to work through the next example, too.

Estimate residual density after PCT

This example builds on the same based stand conditions.   This time, we will assume the stand is now 40 years-old with a known (measured) density of 1400 trees/ha, and it is known to have been pre-commercially thinned.   In this case, because it has been thinned, TIPSY can only estimate the residual density immediately after PCT.   To use the Existing Stand Option with PCT, we must also assume it was thinned before crown closure, so initial density doesn't matter very much.

  1. Starting where we left off in the previous example, open the Stand Specifications dialogue box again and notice the current initial Density setting of 8521.   With PCT, the Existing Stand Option needs an initial density value high enough to support the calculated residual density after PCT.   For now, we can assume 8521 will be enough.

  2. Next, check the box next to PCT in the Treatment area at the bottom.   Then click the To button below it to open the Residual Density dialogue box and click the button labeled Calculate from Existing Stand Data.  This opens the Existing Stand Data (after thinning) dialogue box.

  3. Enter 1400 trees/ha then click the BH Age:... button to open the the Age/Height dialogue box.

  4. Like before, ensure the Lock Site Index box is checked to force TIPSY to adjust the Top Height value to conform with the known site index and age values.

  5. Select the TIPSY Age option then enter 40 years and click OK to return to the Existing Stand Data (after thinning) dialogue box.

  6. Notice the information displayed on the BH Age: ... button has been updated with the new BH Age (32.0 yrs) and Top Height (14.2 m) values reflecting a site index of 19m.   Click OK to return to the Residual Density dialogue box, and notice the new estimated residual density of 1535 trees/ha.

  7. Click OK again to return to the Stand Specifications dialogue box and notice the label on the PCT To button now reads to 1535.  Also notice the initial Density remains at 8521 from the first example.   Again, we are assuming it was thinned before crown closure, so initial Density doesn't matter very much.   In this case, 8521 was enough to support the residual density of 1535.

  8. Click OK to view the Stand Description display.   Notice the PCT information has been added.  Now, you can open any of TIPSY's Output Tables to examine various yields.

  9. In the Preferences Menu, select PCT pre/post data.  Then click the Yield Table icon on the Toolbar.  Select one or more Merchantability Limits and click OK to display the Yield Table.   Notice the pre- and post-PCT rows with a Top Height of 4m, TIPSY's fixed PCT height for the interior.   The post-PCT row reports the residual density of 1535.

 About Jobs Tables

 Users Settings

Default Values

The Jobs Output Table is accessed through the Tables Menu or the Tool Bar icon above.   A Jobs Table reports labour estimates (person days per hectare, PD/ha) associated with silviculture, harvesting and manufacturing operations.

 Users Settings

TIPSY contains recommended default values.  Users can substitute local information through the Jobs dialogue box, which is accessed with the Pencil Icon in the Toolbar.

Total site area, at the bottom of the dialogue box, is only required if pre-commercial thinning or brushing the removal of competing vegetation from around seedlings which have not yet reached "free growing" stage is specified.

Default Values

TIPSY's default values are based on district averages, functions developed by Mike Stone (1992), and employment statistics reported by Forest Practices Branch (FPB).

In the latest update (2008), the functions and the provincial default job averages remain unchanged.  However, the regional default jobs were re-averaged to represent the new Ministry regional structure as follows:

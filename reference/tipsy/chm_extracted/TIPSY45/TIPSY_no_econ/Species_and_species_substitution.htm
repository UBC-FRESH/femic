Species substitution

TIPSY's database stores species-specific yields as a function of height.  TIPSY then applies a site index curve to this data to derive yields as a function of age.

Species Selection in TIPSY is limited to 18 species, which all have their own BC-derived site index curves.   However, TIPSY's database only contains yield data for 10 of these species.  For the remaining 8 species, TIPSY automatically substitutes yield data from species with similar growth habits, as noted in bold within the first table below.

The second table lists recommended manual (user effected) species substitutions for 6 additional species not available in TIPSY.  E.g., grand fir (Bg) yields can be approximated using coastal western hemlock (Hwc) yields from TIPSY.

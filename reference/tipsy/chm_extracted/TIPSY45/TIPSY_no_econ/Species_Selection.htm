Species selection is accomplished through the Species Specifications dialogue box, which is accessed through the main Edit Menu or the icon on the Tool Bar.  Species Selection is managed with the Add and Delete buttons in the lower right corner.

Add Button

Opens the Add a Species dialogue box.   Select a species from the list supported by TIPSY.   Selecting the Regional option, localizes the list to either coastal or interior species depending on the Forest Region selected in the Project Title and Stand Geography dialogue box.   

Delete Button

Deletes the selected species row from the table.

Multiple Species

Up to five (5) species can be selected.   Yields for multiple species stands are pro-rated, which limits interpretations of those yields.  Therefore, users are encouraged to explore this topic before using TIPSY multi-species yields for operational decision support.   Also see Percent Composition.

A species can also be selected a second time to allow for genetically improved stock alongside unimproved stock. When a second incidence is added, you will be asked to rename it.   You can also rename any species (row), at any time, by double-clicking its name in the left-most column.   Species names are used in tables and graphs.

Other Species

Yields for species not directly supported by TIPSY can estimated using the ministry-recommended list of Species Substitutions.    This same list is used by BatchTIPSY.

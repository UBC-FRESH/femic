TIPSY's two Existing Stand Data dialogue boxes, labelled before and after (PCT) thinning, provide an alternative starting point for the iterative (trial and error) process of estimating an initial Density value based on data from an existing (established) single-species stand.   Both dialogue boxes contain the same settings and both automatically adjust TIPSY's main initial Density setting in Stand Specifications.

(before thinning)

The Existing Stand Data (before thinning) dialogue box is accessed from the initial Density dialogue box in Stand Specifications.   It is used with data from stands that have not been thinned.   This option is preferred over the (after thinning) option below, because it produces better predictions of density-related tree characteristics, i.e., crown size and stem taper/volume.

(after thinning)

The Existing Stand Data (after thinning) dialogue box is accessed from the (PCT) Residual Density dialogue box in Stand Specifications.  It is used when only post-PCT stand data are available.  

Common Settings

Both Existing Stand Data dialogue boxes (before and after thinning) reflect the same settings used to predict initial Density as a function of Age or Height & No. of Trees.   A Basal Area option is not available, but may be added in the future.

The currently selected species-specific Site Index is shown.   This is used in subsequent calculations of Top Height and age.

No. Trees/ha

Enter stand density (trees/ha) for the existing (established) stand.  Note:  subsequent changes affecting Site Index (incl. top height and age) may automatically adjust density.   Consequently, you may wish to enter density last.

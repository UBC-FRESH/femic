Mechanical: 0.87 PD/ha district average. This is the same for all districts (provincial average).

Function:

Mechanical: no function is available

Manual:

JOBS = f (Area, Slope, Trees removed, Dbh, Regional adjustment)

JOBS = -1.3215 - (0.024 * A) + (0.0878 * S) + (0.000126 * T) + (0.142 * D) + R

If JOBS < 1.0, then JOBS = 1.0

If JOBS > 6.0, then JOBS = 6.0

where:

JOBS = Average number of person days/ha

A = Area treated in hectares (default = 50ha)

S = Average slope (%) of ground (default = 10%)

T = Average number of trees removed (calculated by TIPSY)

D = Average diameter (cm) of the stand prior to treatment

R = Region-specific adjustment

Comments:

  • The application age varies but will conform to the height (4 or 6 m) at which TIPSY pre-commercially thins the stand. If you pre-commercially thin a stand with multiple species, the age at which the thinning takes place will be different for each species. This is because thinning coincides with certain heights, each species attaining that height at a different age. The percent composition of each species has no affect on the timing of the thinning.

  • The impact of OAF’s is incorporated automatically when TIPSY calculates the number of trees removed (i.e. post OAF density – residual density = number of trees removed).

Site Index: Total age and YTBH

Site Index in TIPSY

Most Site Index (height-age) curves are based on breast-height (BH) age.  However, TIPSY requires height-age curves based on total age (i.e., germination age) in order to predict height growth.   The conversion from BH age to total age requires an estimate of the number of years from germination to breast height (YTBH).

YTBH functions

Most Site Index curves are published with simple YTBH functions, largely based on natural stands.   Lacking better information, TIPSY applies these to planted stands, too.

The table below lists the YTBH functions incorporated in TIPSY.   Note that after YTBH is computed, the answer is forced to 1-year steps, starting at 0.5 years.

Height growth to BH

In order to extend height-age curves below BH, the following functions are incorporated in TIPSY to predict height for each year below BH, i.e., from age 0 (seed) to the YTBH age (above).   Besides extending site curves based on BH age, the functions below are also applied to site curves that start at total age zero (height = 0) because accuracy is improved.  For example, Bruce's (1981) site curves for coastal Douglas-fir perform poorly below BH, particularly on low sites.   However, the functions below are not used when Juvenile Height Growth models are applied.

NOTE:  The functions below have only been programmed into TIPSY, and not Sindex (see SITETOOLS). Therefore, other applications using Sindex (e.g., SITETOOLS, etc.) will report different results below BH.   These equations describe the height-age relationship of trees that regenerate naturally.

Coastal Douglas-fir

H = a A^b

Where:

H = top height

A = age from seed

b = 1.987/(1 + e^ (-24.8033 + 0.34589 SI))

SI = Site index

a = HBH1/(Y2BH1^bc^Y2BH1)

Y2BH1 = round (Y2BH + 0.499)

HBH1 = height at Y2BH1 (from site curve)

^- means ‘raised to the power of’

The preceding equation form will also be used for other species as data become available. Until then, we have implemented a simpler version where curve shape does not depend on site quality. That is:

Other species

H = a A^2

Where:

H = top height

A = age from seed

a = HBH1/(Y2BH1^2)

Y2bH1 = round (Y2bH + 0.499)

HBH1 = height at Y2bH1 (from site curve)

^- means ‘raised to the power of’

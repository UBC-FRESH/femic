Graphing Output with Plotsy

Data from TIPSY Output Tables can be graphed with Plotsy, the plotting program packaged and installed with TIPSY and other Ministry growth and yield applications, e.g., SITETOOLS, TASS III.   Plotsy can also plot stem maps.

Follow these steps to send TIPSY Output to Plotsy for graphing:

Step 1:

Open the TIPSY Output Table  containing the data you wish to graph.

Step 2:

Send (export) the data to Plotsy with the Toolbar icon shown above, or use the Plot command in the File Menu.

This opens Plotsy's Add or Remove Series or Add or Remove Themes dialogue box, depending on the type of data.

  • Plotsy treats data reported by age or height as Series data.  This includes Yield Tables and Custom Tables.   "Columns" refers to column variables in these TIPSY Output Tables.   Each variable is plotted as a separate line/curve, with age (or height) on the x-axis..   

  • Data reported by diameter class (and stem maps) are treated as Theme data.  Each theme represents data for a single age.  Diameter-class data are plotted as bar graphs, with diameter class on the x-axis.

Step 3:

From the list on the left, select the variable(s) you wish to initially graph and move them to the list on the right with the Add or Add All buttons.

  • This selection defines the initial graph produced by Plotsy.

  • Regardless of this initial selection, TIPSY always sends Plotsy all the data from the current TIPSY Output Table, plus the full set of Custom Table variables.   This allows production of many additional graphs without returning to TIPSY.

  • In the upper left corner, note the Column Group drop-down pick-list.   This can be used to subset the list of variables on the left.

Step 4:

Click OK to open Plotsy and view your initial graph.

Refer to Plotsy Help for instructions on how to modify the graph and create additional graphs from the imported TIPSY data.   Plotsy provides many options for customizing axes and overlaying graphs.

NOTE:  Conflicts may occur when attempting to plot data from more than one application at the same time (e.g., TIPSY and TASS III).

CWD: Integration with Snag Model

TIPSY provides two types of information: direct and derived. Variables of the direct type are found in the TIPSY tables that were created from TASS model runs. Derived variables are created within TIPSY through internal models. TIPSY output of both variable types may involve interpolating between "known" data points to get the requested specifications.

The CWD tables contain derived information. In general, the amount of CWD is calculated from fall information obtained from the Snag Table, which is also derived. As the Snag Table does not provide volume estimates by size class, volume estimates of CWD by size class are calculated from the number of snags that fell within a dbh class. Other considerations such as OAFs are also factored in. As such, the reported CWD values have been adjusted to provide estimates consistent with the live tree tables.

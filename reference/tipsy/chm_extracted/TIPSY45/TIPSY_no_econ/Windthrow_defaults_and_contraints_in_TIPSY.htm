Location models also use coefficients to calculate the effect of windthrow.  These can't be changed.

Constraints

The windthrow model works only with certain combinations of variable retention inputs.  For example, you can't use windthrow with the formula method of edge length determination and a crown area that is partly aggregated and partly dispersed.  TIPSY will alert you to these limitations.  BatchTIPSY produces an error message in its .err file.

TIPSY won't allow you to enter a value outside of the ranges in the table above.  In BatchTIPSY, if an input column contains data beyond the available range, it produces an error message and won’t run that row of the table.

We have developed VR coefficients for only four species in TIPSY. If you use windthrow and variable retention for any other species, the program automatically makes substitutions. See Table of VR species substitutions.

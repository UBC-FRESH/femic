Stem Maps

Stem maps can be graphed with Plotsy using the Plot Initial Stem Map button in Stand Specifications.   Plotsy stem maps represent tree spatial distribution patterns over a square one-hectare plot that reflect the current settings for Regeneration Method and Density in Stand Specifications.   While stem maps generated by TIPSY do not represent actual tree locations from TASS, they provide a close approximation for visualizing the different spatial distributions represented by TIPSY yields.

For more information on plotting data, see Graphing Output with Plotsy.

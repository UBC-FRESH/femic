Site Index Class conversion

Today, most forest inventories and silviculture surveys report Site Index as a continuous variable.   However, historic inventories and silviculture tools often relied on categorical Site Class the measure of the relative productive capacity of a site for a particular crop or stand, generally based on tree height at a given age and expressed as either good, medium, poor or low estimates instead.   The following table provides Site Index estimates for Site Class the measure of the relative productive capacity of a site for a particular crop or stand, generally based on tree height at a given age and expressed as either good, medium, poor or low categories, which can be used in TIPSY if better Site Index estimates are unavailable.   However, just about any Site Index estimate would probably be as good or better.

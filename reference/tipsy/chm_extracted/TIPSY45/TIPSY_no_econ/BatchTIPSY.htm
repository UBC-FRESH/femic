BatchTIPSY

About BatchTIPSY

BatchTIPSY generates yield tables for large multi-stand datasets, like those used in timber supply analysis.  It handles most of the treatments and variables that interactive TIPSY does, provided they impact volume. To start BatchTIPSY from within interactive TIPSY, click on the Toolbar icon shown above, or select Start BatchTIPSY in the File Menu.

BatchTIPSY uses three files;

  • an input data file

  • an output data file, and

  • a BatchTIPSY (.BTP) file, which defines input/output file formats and processing specifications.

The information contained within a .BTP file is accessed and edited through a series of dialogue boxes arranged in sequence to form a "wizard" feature similar that found in other applications.

BatchTIPSY provides two options for creating a .BTP file:

  1. To create a new .BTP file from scratch, select New from the File Menu, or use the associated Toolbar Icon.   The wizard then walks the user through all the steps sequentially.   

  2. Or, open an existing .BTP file by selecting Open from the File Menu, or use the associated Toolbar icon.   BatchTIPSY then processes (runs) the file and displays the output file on-screen.    The user may then access and edit the information within selected dialogue boxes.

In both cases, once all dialogue boxes have been completed, select Finish, then Run to generate the output file.   The Finish button is required after changes to any dialogue box, but not after changes to the input file itself.  Also, be sure to save the new .BTH file by selecting Save (or Save As) from the File Menu, or use the associated Toolbar icons.   

If BatchTIPSY encounters a problem while processing data, it generates an error file and displays a message, including the folder location of the error file.

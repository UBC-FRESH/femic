Overview

Fertilization involves settings in two different locations within Interactive TIPSY.   Settings in Stand Specifications control application timing and effectiveness, while settings within Species Specifications determine which species-specific response models are applied.  I.e., Ministry default response models are applied by default unless custom user-defined response models are specified in Species Specifications.

Stand Specifications settings (age & effectiveness)

To activate fertilization, check the box next to the Fertilization button in Stand Specifications.   Then, click the Fertilization button to define application age (single or multiple) and effectiveness.   This involves a series of fertilization application dialogue boxes described below.   Unchecking the box disables fertilization, but retains the current settings.

Fertilization Application (#)

The Fertilization Application (#) dialogue box is used to define application age and effectiveness of one application event.   Each application event is assigned a number (#).

Application age for natural and planted stands, is defined as years since germination and years since planting, respectively.

Effectiveness (%) is an adjustment (multiplier) applied to volume response.  It is normally used to adjust response models that are based on carefully fertilized research plots (e.g., Ministry defaults) to better reflect operational application realities, e.g., rate and coverage inconsistencies, etc.

80% is normally recommended when using Ministry defaults.  Adjustments may also be based on local experience, including adjustments for (minor) differences in application rates.

TIPSY automatically applies further adjustment  (x 0.75) to the effectiveness value to compensate for competition in under- or over-stocked stands when crown cover is < 30% (low stocking adjustment) or live crown ratio of prime trees is < 40% (intense competition adjustment).

Fertilization Applications (all)

The Fertilization Applications dialogue box provides a table displaying the application age and effectiveness settings of each application event currently defined.   Buttons are provided to add, remove, and edit application events in the table.

Species Specifications settings (response model)

NOTE:  Within most operational applications, the Ministry default models for percentage volume increase are the standard method.

Species-specific fertilization response models are viewed, defined, and selected in the Fertilization Custom Responses dialogue box, which is accessed with the Fertilization Response button in Species Specifications.  The Fertilization Custom Responses dialogue box provides several options for specifying custom response models, or using TIPSY's built-in Ministry default models (the default selection).

Ministry default models are species-specific.  Each one is associated with a specific elemental application rate (e.g., 200kg N + 50kg P/ha).

The Fertilization Custom Responses dialogue box displays a table describing the response model to be applied to the species currently selected (highlighted) in Species Specifications.   Table response values are specific to the site index currently assigned to the species.

A row of two (2) radio buttons near the top enables table response values to be viewed/edited as:

  1. percentage volume increase (%):  This is the default method and is commonly used in operational settings since it can be applied to a range of stand conditions, i.e., densities.  The Ministry default models use this method.

  2. absolute volume increase (m3):  Application of this type of response model is restricted to stands with one specific initial density, 1100 stems per ha for the default models.  These response models are intended mainly for research and exploratory purposes.

The three (3) radio buttons directly above the table determine the source of the response model selected and displayed in the table:

Ministry defaults

This selects the species-specific Ministry default response model built into TIPSY.   If no default model exists for the selected species, the response table values reflect zero response.

Custom Response Options

  • User-defined custom response models will be automatically capped at 200% of the ministry defaults.

  • If a user wishes to restrict application of custom response models to specific application rates, vegetation types (e.g. BEC), and/or physiographic areas, they must do so manually since TIPSY has no options for this itself.

  • Response values represent the % increase in 10-year total volume increment beginning at the specified age.   See Implementation for details.

Input File

For maximum flexibility (reusing and sharing), custom response models can be defined in a specially formatted ASCII text file.   Response files must first be imported through the Edit Menu before this option can be enabled.

Interactive

Interactive mode allows users to create and edit table values to produce a custom response model for a particular species and site index.   This form of custom model will be saved in the .TIP file, but it cannot be easily re-used or shared the way an Input File response model above can.

  • Initially, the interactive response model reflects the default model, until it is edited.

  • The two age end points with zero responses cannot be deleted.   They anchor the response model and facilitate extrapolation.

  • Interactive response models do not automatically change (or adapt) when the species' site index is changed.   They must be redefined.

  • Furthermore, they do not remain associated with the species, in general.   I.e., when a new incidence of a species is added, the response model reverts to the ministry default.

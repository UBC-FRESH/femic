Output Tables

After a regime (project) has been defined using TIPSY's four main dialogue (settings) boxes, many different types of Output Tables can be viewed.  Follow the links below to explore each one.   See Variables Reported in Output Tables for lists of variables reported in each table.

Output Tables are selected and viewed on-screen using the Table Menu (Alt+T), or by clicking the associated Toolbar icon, as shown below.

On-screen Output Tables can be Printed, exported as a text file, or exported to other programs for graphing, economic analysis, or carbon budget modelling.  Tables can also be copied to the Windows clipboard by highlighting all (or part) followed by Ctrl+C, or right-click on the table for a command menu.

NOTE:  For multiple-species, tables only report values for all species combined.

TIP:  To minimize screen clutter, select Single View in the Preference Menu.

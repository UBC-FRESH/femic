Variable Retention: Batch

In BatchTIPSY, you will find the VR option in the Input Variables dialog. Select this checkbox to activate the VR dialog. Once VR has been activated, you can access this same dialog through the Edit menu.   Click here for information on activating the windthrow model in conjunction with VR.

Note:  There has been some confusion about how to enter % aggregate area and % dispersed area in the VR dialog.  Just enter the % aggregate and BatchTIPSY will calculate the percent dispersed.  This is similar to how interactive TIPSY works, though much less intuitive when you can't actually see the percent dispersed change as you change the percent of aggregated retention.

Following the release of version 3.2, we changed the Variable Retention dialog in BatchTIPSY to make it less 'interactive'.  This was necessary so that BatchTIPSY could be incorporated into other programs such as Woodlot, where the interface is stripped away from the BatchTIPSY executable.  The radio buttons in the dialog were removed and now users will specify all VR inputs at one time, instead of being forced (or able) to select a particular edge length calculation methodology in the dialog.  If you open an older BatchTIPSY file with variable retention, you'll be alerted to the change.  Variable retention will be disabled until you go to the new dialog and fill in missing data.  The new input required is the location (in the input file) for edge length calculation methodology and for crown cover calculation methodology (U for user specified, F for formula (basal area) -- only used for the formula methodology of edge length calculation).  It's necessary to specify column locations for all variable retention variables, even if the columns aren't used in the input file.

Initial edge length can be given in three ways:

  • using a pre-determined formula  (F)

  • user specified (U), and

  • geometric (G)

For the geometry option, your input file must indicate average group size and shape. Use one case-insensitive character in the input file as follows:

C: circle

S: square

1-9: rectangle ratio (where the number is the width of a rectangle with a height of 1 unit)

I: irregular (12x1 rectangle)

If BatchTIPSY doesn’t recognize the character in your input file, it will use a circular shape for its calculations.

Crown cover percentage retained is typically input directly from the file. However, if you are using the formula to calculate edge length, you can choose to input the retained basal area instead. In this case, the program will calculate the crown cover using an internal formula based on the species.

Your input file should also include the retained top height. As with TIPSY, the top height may be modified if the stand has a regeneration delay (see Example 2).

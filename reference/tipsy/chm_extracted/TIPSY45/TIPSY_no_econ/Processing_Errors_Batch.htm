Processing Errors, Batch

When BatchTIPSY isn't able to process every line in the input file, it generates an error log and displays a message giving you the location of the file, usually your working folder. The error log identifies the reason for the error, the line in the input file that contains the error, as well as the corresponding table number in the output file.

You might need to consult the online documentation for more specifics about the reason BatchTIPSY isn't able to complete the processing. Many errors will actually be due to the limitations of TIPSY's database itself.

Open the error log in Notepad or a similar text editor. You'll see messages similar to those in the example below.

Running batch: C:\TIPSY41\BATCHEG.BTP
Input file: C:\TIPSY41\BATCHIN.DAT
Output file: C:\TIPSY41\BATCHOUT.DAT
Error file: C:\TIPSY41\BATCHEG.ERR

Line 2 - Table Number 123

- Error: height or site index must be supplied for dominant trees with crowns extending above the general level of the canopy and receiving full light from above and partly from the side; taller than the average trees in the stand with crowns well developed species 3 (SX)

Line 3 - Table Number 133

- Error: No TIPSY Volume curve mapping for input species code 'HM'

Line 4 - Table Number 213

- Error: percent composition for 3 mixed species adds up to 91% instead of 100%

Jobs: Calculating Total

Total jobs for any row of the Jobs table is the sum of the silviculture jobs and the harvesting/manufacturing jobs in that row.

In the Jobs dialog box, the units are displayed as person years per thousand cubic metres. These units are the industry standard. For simplicity, TIPSY converts these values to person days per 1000 m3 using the following formulation:

PD/1000 m3 = PY/1000 m3 x 200 days

where:

200 days represents the number of working days per year.

In the summary at the top of the jobs table, harvesting and manufacturing jobs are expressed as PD/1000 m3.

TIPSY then translates PD/1000 m³ to PD/ha as follows:

JOBS(PD/ha) = JOBS(PD/1000 m³) * Merchantable volume(m³/ha 12.5+) / 1000

This is so TIPSY can display all jobs in the same units in its output, including the total number of jobs. To better understand these calculations, see Jobs Table, a Detailed Example.

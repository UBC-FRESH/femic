Select Curves

The Select Curve(s) dialogue box appears when any of the assignment hotlinks are clicked within the Assignment Details box at the bottom of the Species Assignment Table.

Site Index Species:

Selects the species providing the site index equation.

Site Index Equation:

Selects the assigned Site Index equation (citation).   The drop-down list contains all the equations available for the selected Site Index Species in SiteTools (SINDEX).   A checkbox is provided to select the Ministry Recommended Curve.   The Notes button displays addition information about the selected curve (citation).

Growth Intercept Model:

Selects the assigned  Growth Intercept Model (citation).  The Notes button displays addition information about the model.

Output Preferences settings contain two important GI settings that control the application of this GI setting.

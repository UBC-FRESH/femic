Species Assignment Table

Caution:  The default Species Assignment Table reflects ministry standards incorporated in many other ministry systems, e.g.,  inventory, timber supply, RESULTS, SIBEC, etc.  Therefore, table modifications are discouraged for related applications.   The Restore All Defaults button will remove any modifications.

SiteTools uses the Species Assignment Table to assign site index curves to species via species codes (136 in the default table).   The table can be viewed and edited through its command in the Preferences Menu.

To use the Species Assignment Table settings in Species and Curve Selection, select the "All Species" option in Calculator and Table modes.   Batch mode uses the Species Substitution Table exclusively.

Table Columns

Column 1:      Species Code (standard ministry codes).

Column 2:      Common Name for the species in column 1.

Columns 3-6:   For each combination of Location (Coast vs Interior) and Regeneration Method (Natural vs Planted), a species code representing the species assigned to provide the site index curve (equation) for the species in Column 1.  .

  • SINDEX only provides SiteTools with site index equations for the 24 common BC species that are short-listed in Common Species.   Default assignments for these 24 species consist of identical species code in Columns 1 and 3-6.   This directs SiteTools to use site index equations derived for that species in all cases.

  • Species other than the 24 common species are assigned species codes in columns 3-6 corresponding to the substitute species, which corresponds to one of the 24 species in SINDEX, i.e., the short-list in Common Species.   Defaults reflect the standard species substitutions used in the provincial inventory, etc.

  • SINDEX, and therefore SiteTools, contains several different site index equations for some species.   See Assignment Details below.   

Columns 7-8:  The assigned Growth Intercept (GI) equation by Location (Coast vs. Interior).  Defaults assignments are restricted to species having their own species-specific GI equations in SINDEX.   See Assignment Details below.

Assignment Details

Clicking on a species (row) highlights it displays Assignment Details for the species below the table.

Species Code:   Defaults are standard ministry species codes.  Click the hot-link to edit.

Species Name:   Defaults are standard ministry species common names. Click the hot-link to edit.

Coastal vs. Interior checkbox:   Enables separate assignments by Location.

Natural vs. Planted checkbox:  Enables separate assignments by Regeneration Method.

When both checkboxes are unchecked, a single substitute species assignment is displayed, along with the citation for the associated site index curve assignment.   The adjacent All label indicates the assignment applies to all Location and Regeneration Methods..

Multiple assignment pairs are displayed when one or both checkboxes are checked.

Adding or Editing Assignment Details

Caution:  The default Species Assignment Table reflects ministry standards incorporated in many other ministry systems, e.g.,  inventory, timber supply, RESULTS, SIBEC, etc.  Therefore, modifications are discouraged for related applications.   The Restore All Defaults button will remove any modifications.

To add a new species row, click the "Add New Species" button and follow the prompts.

To edit existing curve assignments, open the Select Curve(s) dialogue box by clicking a specific hot-linked curve assignment within the Assignment Details at the bottom.

On-Screen Reports, Interactive

Both interactive modes, Calculator and Table, automatically provide on-screen reports on the right-side of the screen.

Formatting of Table reports is controlled by Table Specifications.   Formatting is fixed for Calculator reports.

To Print on-screen reports, use the Print Command in the File Menu, or the Print icon in the Toolbar.   

To Copy or Save the content of on-screen reports in a number of files formats, use the Report commands.

Alternatively, right-clicking on the on-screen report itself brings up a menu containing all the Print, Save, and Copy commands.

TIP:  You can create printed or electronic copies (e.g., PDF) of custom site index Tables for field use.

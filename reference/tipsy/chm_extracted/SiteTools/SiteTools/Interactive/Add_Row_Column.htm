Add Row/Column

The Add Row/Column dialogue box is accessed using the edit icons in the Table Specifications section of Table mode.

To specify a Row/Column format, select one of the following three (3) options for defining the Row/Column values in the on-screen Table:

Value(s):   enter a list of individual values, e.g., 5,12,25,75

Range:   enter values defining a range, e.g.,
                From 5 To 50, in Steps of 5 (coded as 5-50:5 in Custom).

Custom:   enter any combination of values and ranges, e.g., 5-50:5,75,100

The Tabular Output section in Preferences provides further control of tabular formatting.

Calculator Mode

Calculator mode is selected using the Calculator tab in the top-left corner of the main screen directly below the Toolbar.  The on-screen report (right side) is updated automatically to reflect input settings (left side).

Settings in the first three (3) sections listed below are shared by both interactive modes, Calculator and Table.

  • Species/Curve

  • Calculation Settings

  • Method

  • Input & Output (Calculator mode only)

Inputs (on the left) are entered in boxes.   Outputs (on the right) are updated automatically to reflect Inputs.    Note, variables appearing in the Input and Output sections are determined by Method settings.

When Species Conversion models exist in SiteTools, additional Site Index estimates are also reported for other (target) species based on the Site Index of the selected (reference) species.

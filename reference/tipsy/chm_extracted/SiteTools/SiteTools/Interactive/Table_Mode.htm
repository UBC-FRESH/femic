Table Mode

Table mode is selected using the Table tab in the top-left corner of the main screen directly below the Toolbar.  The on-screen report (right side) is updated automatically to reflect changes in the input settings (left side).   On-screen reports can be saved; the data can also be graphed with PLOTSY.

Settings in the first three (3) sections listed below are shared by both interactive modes, Calculator and Table.

  • Species/Curve

  • Calculation Settings

  • Method

  • Table Specifications (Table mode only)

This section defines row and column formatting for the on-screen table displayed on the report (right) half of the main screen.   Row and column variables are determined by Method settings.

Multiple formats can be created; only checked format(s) are active.  Duplicate values (format overlap) will be eliminated as long as Sort is checked (the default) in Output Preferences.

Icons beside each format list provide the following edit functions:

Switch row and column variables.

Open the Add Row/Column dialogue box to add and configure a new format specification.

Open the Add Row/Column dialogue box to edit the selected (highlighted) format specification.

Delete the selected (highlighted) format specification.

Location

Regeneration

 Calculator and Table modes share the same Calculation Settings containing the following two (2) settings:

Location

Coast or Interior

Location controls curve selection only when the selected species (code) has separate coast and interior curves defined in the Species Assignment Table.      

Regeneration

Natural or Planted

Regeneration controls curve selection only when the selected species (code) has separate natural and planted curves defined in the Species Assignment Table.

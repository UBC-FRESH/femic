Method

Calculator and Table modes share the same Method settings.  SiteTools supports four (4) calculation methods that estimate different values from various inputs.   In Table Mode, this setting also controls the general format of output tables.

  1. Height - by age and site index:    Top Height See Site Height as a function of age and Site index

  2. Site Index - by age and height:    Site index as a function of age and Top Height See Site Height

  3. Age - by height and site index:    Age as a function of Top Height See Site Height and Site index

  4. Years to bh - by site index:            Years to breast height as a function of Site index

The associated Age definition,  Breast height age or Total age, is selected using the radio buttons underneath.

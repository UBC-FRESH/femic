Calculator & Table Modes

Interactive Calculator and Table Modes are accessed through tabs in the upper left corner.

Calculator mode supports single, interactive calculations.

Table mode formats and displays custom look-up tables.

The input (left) side of the screen:

  • Both of these interactive modes share the same settings for:

Species & Curve Selection

Calculation Settings

Method

  • Unique settings for Calculator and Table mode appear at the bottom.

The output (right) side of the screen:

Different types of reports are displayed on-screen for Calculator and Table modes.

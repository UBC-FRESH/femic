Graphing with PLOTSY

Graphs of Table data can be produced by clicking the Send data to PLOTSY (graph) icon on the Toolbar.

PLOTSY is a graphing program created for, and distributed with, ministry growth and yield software, e.g., SiteTools, TIPSY, etc.   Clicking the icon, opens PLOTSY and displays the Add or Remove Series dialogue box displaying a list of data series based on the current SiteTools Table.

Select one or more series to graph and click OK to view the graph in PLOTSY.   PLOTSY also provides may options for modifying the graph.   See PLOTSY Help for more information.

NOTE:   Selecting  all series initially provides the most flexibility in PLOTSY.  Only Table data can be graphed.   The PLOTSY icon is inactive in Calculator mode and Batch mode.

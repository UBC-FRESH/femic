Main Screen

Also See:  Getting Started

SiteTools' main screen has the following features:

Main Menu:

Windows-style command menu, located in the top, left corner.

Toolbar:

Windows-style toolbar containing shortcut icons for common commands, located directly under the Main Menu.

The screen is divided vertically down the middle.

Input (left side):

Three tabs at the top select the mode of operation:  Calculator mode, Table mode, and Batch mode.

Report (right side):

Displays on-screen output for each mode in report format:.

On-screen Reports, Calculator and Tables modes.

On-screen Reports, Batch mode.

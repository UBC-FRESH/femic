Getting Started

SiteTools' main screen is split vertically down the middle, with settings and inputs on the left and reports (output) on the right.

Detailed context-sensitive Help is accessed with F1 after selecting a setting in question.

The three (3) tabs in the upper-left corner are used to select the mode of operation:

  • Calculator mode:  functions as an interactive on-screen Site index calculator.

  • Table mode:   generates customizable, species-specific, Site index tables on-screen.  Custom tables can be graphed with Plotsy and/or saved in multiple file formats, including PDF, for future reference.

  • Batch mode:  automates Site index calculations within large data files.

Both Calculator and Table mode give users three (3) options for Species and Curve Selection;  the Common Species option is sufficient for most users.   The three options differ in access to Ministry recommended curves and the Species Assignment Table.   Batch mode references the same Species Assignment Table.

SiteTools incorporates and integrates four types of Site index-related functions:

  • site index (SI, height-age) models

  • growth intercept (GI) models

  • juvenile height growth (JHG) models

  • species conversion models

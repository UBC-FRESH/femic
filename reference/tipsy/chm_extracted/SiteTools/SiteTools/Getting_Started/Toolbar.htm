Toolbar

The row of Toolbar icons below the Main Menu function as short cuts for frequently used commands.

NOTE:   Hovering the mouse pointer over each icon reveals its label.

Toolbar Icons

New:  starts a new project by restoring input settings to their defaults.

Open a saved project settings file: .STI for interactive calculator and table modes; .STB for Batch mode.

Save the current project settings:   .STI for interactive calculator and table modes; .STB for Batch mode.

Print:  Sends the report (right side) to your printer.

Print Preview:  preview the print layout on-screen.

Copy Report:  If no text was highlighted first, it copies the entire report (right side) to the Windows clipboard as delimited text.   Otherwise, it copies only highlighted text, just like (ctrl+C).   The copied text can then be pasted (ctrl+V) into MSWord, etc.

Send data to PLOTSY for graphing.  See Graphing with PLOTSY.

Help:  Opens the Help function which explains how to access and use all the features in SiteTools.   The F1 key opens Help, too.

The Preference dialogue box is accessed with the Output Preferences command within the Preference Menu of the Main Menu.   It has two (2) sections::

Tabular Output

Format settings specify the number of decimals reported for Age, Height, and Site Index values.   Check boxes control sorting of row and column values within tables.

Advanced Settings

Site Index Estimation Method

Iterative:  Disables direct SI calculations to ensure consistent results when used in subsequent (reverse) iterative calculations to predict height or age from SI.

Direct (when available):   The default setting whereby SiteTools uses a combination of iterative and direct calculation processes (see table below), which yield consistent results with all equations and calculation methods.   Only a few BC species have SI equations that support direct SI calculation from age and height.   While theoretically slightly more accurate, users should be aware that direct SI calculations can produce inconsistent results if used in subsequent (reverse) iterative calculations to predict height or age from SI.

GI Check boxes

Uncheck to disable recommended default settings:

Unchecking the first box prevents the application of Growth Intercept curves, regardless of other settings.

Unchecking the second box only allows Growth Intercept curves to be applied to the species they were developed for, and not to surrogate species as well.

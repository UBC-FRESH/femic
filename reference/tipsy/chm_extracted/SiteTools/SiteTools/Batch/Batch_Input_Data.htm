Files to Process

In Batch mode, with Multiple Files unchecked, the Files to Process section appears at the top of the input (left) side of the main screen.  This section controls selection and processing of data files, one at a time.

There are four (4) buttons down the right side of the Files to Process section:

  • Import Data is used to select an existing input file (ASCII text), and then define/select its format Template.   After data are imported, details are displayed to the left of the buttons.
    The default location for input files is ...My Documents/Site Tools/Samples/, but they can be read from other locations, too.

  • Paste Data is used to paste data (ASCII text) previously copied to the Windows Clipboard, and then define/select its format Template.

  • Output filename opens the Output filename dialogue box to select an output file creation option.  Details of the current selection are displayed to the left of the button.

  • Process saves results to the designated output file.   Before processing, be sure to configure Calculation Settings and Output Columns.
    Note:  results are continuously previewed in the on-screen report on the right side of the main screen.

In Batch mode, the Edit Input Column dialogue box is accessed from the Import Text File Format dialogue box.   The Edit Input Column dialogue box contains the following settings for an individual column within an input file:

Process Column

To skip processing this column, uncheck this box.

Type (and Other Name)

SiteTools will automatically recognize these variable names in datafile headers.  

·         "age", "total age"

·         "bhage", "bh age", "breast height age"

·         "y2bh", "years to breast height",

·    "height", "ht",

·         "site index", "siteindex", "si",

·         "species", "spc", "sp",

·         "regen", "regeneration",

·         "loc", "location",

·         "est", "estimate", "estimatemethod"

All other names in headers must be manually assigned to SiteTools variables using the Type drop-down menu.

Columns identified as "Other" can be assigned an Other Name for reporting purposes, but they are not used in calculations.

Column

Identifies the data column number.  Zero (0) is the first column, one the second, etc.

Scaler

Defines a multiplier to be applied to the values read from the input file.  Default = 1.0000

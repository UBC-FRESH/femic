OnScreen Reports, Batch

Batch mode provides on-screen output report previewing on the right-side of the main screen.  On-screen previews are limited to the first 500 rows of output.  Checking plain text preview switches the preview to simple comma delimited format.

Output table formatting and variable inclusion are controlled by Output Columns settings.

To Print on-screen previews, use the Print Command in the File Menu, or the Print icon in the Toolbar.   

To Copy or Save the content of on-screen reports in a number of files formats, use the Report commands.

Alternatively, right-clicking on the on-screen report itself brings up a menu containing all the Print, Save, and Copy commands.

Multiple files

In Batch mode, multiple jobs can be configured and processed by checking the Multiple Files box in the top-left corner of the main screen.  A table is provided to create and manage a list of individual jobs (rows).

NOTE:   All files in a given list must be able to share a common (single) input file format Template and output file format.

Step by Step

  1. Click the '+' icon to create a new job (row) and specify its input file.

  2. Define/select the common input file format Template.

  3. Click the 'a|e' icon to specify the job's output file.

  4. Configure the common Calculation Settings.

  5. Select and format the common set of output variables.

  6. Repeat steps 1 & 3 for additional jobs.  Click the 'X' icon to delete a job.

  7. Click the 'multiple file' icon to process all the jobs at once.

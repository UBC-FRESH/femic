Output Columns

In Batch Mode, the Output Columns section is found at the bottom of the input (left) side of the main screen.   This section defines the content and format of output files.

TIP:   Format settings are previewed in the on-screen report.

At the top of the Output Columns section:

Format:   a drop-down pick-list to specify the type of column separator to be used in the output file:  fixed width, tab delimited, comma delimited, space delimited, or other delimiter.

Include file header checkbox to include file descriptors at the top of the file.

Include Column headers checkbox to include Column headers (labels) in the file.

The variable list at the bottom of the section:

Checkboxes next to each variable determine its inclusion in the output file.  Reported variables can include "Input" variables, "Calculated" variables, and "Show" (informational) variables.

List editing icons along the right side operate on the highlighted variable:

The Edit (pencil) icon opens the Edit Output Column dialogue box to edit various format settings for each variable.

Up and down arrows change the variable's reporting position in the output file.

Output filename

In Batch mode, the Output filename dialogue box provides options for creating and naming an output file.   It is accessed with the a|e Output filename button in the File to Process section, or the 'a|e' icon in Multiple Files mode.

Select one of the following options:

Prompt for output filename

Opens "Save As" when each job(s) is processed.

Overwrite input file

Replaces the contents of the input file with the output.

Specify output filename

Output is assigned a new filename, but retains the extension of the input file.

Change the file extension to

Output retains the input filename, but is assigned a new extension.

Place in a different folder

Output retains the input filename and extension, but is placed in a different folder.

Custom

Output is assigned a full directory path, filename, and extension.

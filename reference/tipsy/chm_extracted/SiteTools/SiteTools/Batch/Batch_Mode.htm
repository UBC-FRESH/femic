Overview

Batch Mode enables automated site index calculations within large data sets.   It is accessed using the Batch tab directly below the Tool Bar on the main screen.  The Batch main screen is divided vertically down the middle.   Inputs are defined on the left side.   Output is previewed in the on-screen report on the right side, and written to output file(s).

Single dataset:  Step by Step

Follow the hot links for details.

  1. Leave the Multiple Files box unchecked.

  2. Select input File to Process and specify output file.

  3. Define or select a format Template to read the input file.

  4. Configure Calculation Settings.

  5. Select and format Output Columns variables.

  6. Preview output on-screen.

  7. Click Process to generate the output file.

Multiple datasets:  Step by Step

  1. Check Multiple Files to enable processing of multiple datasets.
    Note: they must all share a common file format Template, Calculation settings, and Output Columns settings.

  2. Select Multiple Files one at a time and specify their output files.

  3. Define or select a common format Template to read all the input files.

  4. Configure the common Calculation Settings.

  5. Select and format the common Output Columns variables.

  6. Preview output on-screen.

  7. Click the 'multiple file' icon to Process All Files at once.

NOTE:  Old batch (.BTH) files created with SiteTools ver. 3.3 can be run using the Import BTH command in the File Menu.

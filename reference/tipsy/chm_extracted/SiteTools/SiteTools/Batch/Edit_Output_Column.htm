Edit Output Column

In Batch mode, the Edit Output Column dialogue box is accessed through the variable list at the bottom of the Output Columns section on the input (left) side of the main screen.   Settings control the formatting of a single variable in the output file.

Show column checkbox controls inclusion of the variable in the output file.

Header enables editing of header text, except for "input" variables.

Units enables editing of units, except for "input" variables.

Format specifies the number of decimal places reported.

Scaler is the multiplier applied to the variable before reporting.  Default = 1.0

Column Width specifies the column width in 1/1000 inch increments.

Column Alignment specifies Left, Centre, or Right justification.

Character From and Width define the starting column number and the total width (number of columns).

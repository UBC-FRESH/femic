Initially, SITETOOLS reads, interprets, and displays the imported file using its default File Settings and highlights the variable names it recognizes in green.  If it fails to recognize the variable in a particular column, the Edit Input Column dialogue box appears.  But, before proceeding with column identification, ensure the other File Settings are correct, and adjust them if necessary, or select an appropriate Template if one already exists.

Template

Templates are files contain input file format settings.

To apply a previously created Template, select one from the drop-down pick-list.

To create and save a new one reflecting the current settings, click the Save Template button.

 Template files have an .STT extension, and must always resided in the Templates folder:
 ...My Documents/Site Tools/Templates/

File Settings

Default file format settings:    Comma delimited (CSV) text file

One header row, containing column variable names

Begin processing (reading file) at line 1

If the format of the imported file does not conform to these defaults, the settings can be changed as follows:

Use the Format drop-down pick-list to select the column separator:
     fixed width, tab delimited, comma delimited (CSV), space delimited, or other delimiter.

If the file has a header row containing variable names, check the Header Row box then select its row number.  This is commonly row 1.

Select a Begin Processing at line (row) number where the data begins.  This is commonly row 2, when there is a header row.

Find Columns

The Find Columns button (re)applies the File Settings above to auto-locate data columns.  Results are shown as green column headers in the sample spreadsheet across the bottom of the form.   Clicking any one of these green column headings brings up the Edit Input Column dialogue box enabling further refinement of column boundaries, variable format, and name.

Columns to Import

This section shows a list of columns, by name, that will also appear in [brackets] within green column headers in the sample spreadsheet.   Use the 3 icons to the right to add, edit, or delete column definitions.   Variables can be skipped by unchecking its box in the list.

The Edit Input Column dialogue box is used to define and assign a variable to each column.

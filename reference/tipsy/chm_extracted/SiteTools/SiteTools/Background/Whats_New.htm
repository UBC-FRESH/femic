What's New?

The following development history for SiteTools documents background and new features associated with each version, in reverse chronological order (i.e., the current version first).

SiteTools version 4.2    June 2021

Key changes include the following:

  • SINDEX updated to ver. 1.52 (32 bit).

  • Updated Batch Help for clarity, including How to Import Data.

  • Minor bug fixes.

SiteTools version 4.1.1    March 2018 

Key changes include the following:

  • SINDEX updated to ver.1.42, which includes new site index curves for lodgepole pine (Nigh, 2017) and western red-cedar (Nigh, 2016).

  • Default species codes adjusted to match VRI (BC Inventory) Tree List

SiteTools version 4.1 

Key changes include the following:

  • Completely revised Windows interface utilizing tabs for calculator, table, batch modes.

  • Addition of a Species Assignment Table used to assign species curves within SiteTools to other species (via species codes).   

  • Exports data to PLOTSY for graphing.

  • Batch now accepts space, comma, and tab delimited ASCII files, as well as fixed format

  • Calculator and table outputs can be saved in multiple file formats.

  • SiteTools 4.1 is a 32-bit program that runs on Windows platforms.   Microsoft NET Framework version 4, or greater, is required.  The SiteTools installation process automatically checks for this and attempts to install or upgrade NET, if necessary.

 

SiteTools version 3.3 (Sept 2004)

 

The first Windows version of SiteTools was released in 1995.   It replaced an MS-DOS version, previously called "Freddie", first released in 1990.

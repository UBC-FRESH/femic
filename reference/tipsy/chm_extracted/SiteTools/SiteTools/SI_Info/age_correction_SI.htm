Age correction, SI models

Some ministry recommended site index models in SiteTools display "(ac)" for age correction following the developers' names.   Notes for these equations also contain the comment "Note: the formulation was modified in 2003 to move the age,height origin from 0,1.3 to 0.5,1.3".   The rationale follows:

  1. This half-year age correction (Nigh, 1995) was implemented to make the models consistent with the definition of breast height age, which is the number of annual growth rings at breast height. Since the innermost ring represents a half years growth (on average), the height-age models actually go through a height of 1.3 at breast height age 0.5, not age 0. Therefore, the age adjustment explicitly incorporates this assumption (i.e., tree reaches breast height midway through the growing season) into the height-age model.

  2. If we make this assumption for the height-age curves, then we should make the same assumption for the years-to-breast-height functions. That is, if the years-to-breast-height functions give us the number of years to reach breast height, then this number should end in 0.5. To do this, we truncate the decimal part of the years to breast height estimate, and then add 0.5.

  3. Total age is just the number of years the tree has been growing. If we add breast height age to years-to-breast-height, we get xx.5 but we should be getting a whole number. This 0.5 year "error" is due to the definition of breast height age. At breast height age nn the tree has only been growing nn-0.5 years since it reached breast height. Therefore,
    Total Age = Breast Height Age + Years-to-Breast-Height - 0.5.

  4. Since Number 1 above is generally accepted, then Numbers 2 and 3 should follow to make the systems internally consistent with respect to the assumptions.

These age corrections are implemented through SINDEX.

Nigh, G.D. 1995. Compatibility improvements and bias reduction in height-age models.  Research Report 3.  BC Ministry Forests, Lands, Natural Resource Operations and Rural Development
, Victoria.

Species Conversion

Species Conversion estimates are only available in Calculator and Batch modes.

Species Conversion models estimate the site index of a target species based on the site index of a reference species growing on the same or similar site.  The table below documents the conversion equations currently available in SiteTools.

NOTE:  SiteTools only provides Species Conversion estimates for species combinations listed in the table below.  Species Conversion estimates are not extended to other species in the Species Assignment Table.

In Calculator Mode

Where Species Conversion models exist in SiteTools, Site Index estimates are reported for all (target) species based on the Site Index of the selected (reference) species.

In Batch Mode

To obtain Species Conversion estimates in Batch mode, the input file must contain values for (target) Species, Reference Species, and Reference Site Index.   The output variable, Calculate: Site Conversion (SI) is the Site Index estimate for the (target) Species, based on the two inputs: Reference Species and Reference Site Index.

Available Models

Each equation is of the form:   Target Species SI = a + b(Reference Species SI),
where a and b are the coefficients of the linear equation.   The equations are reversed algebraically to interchange the target and reference species.

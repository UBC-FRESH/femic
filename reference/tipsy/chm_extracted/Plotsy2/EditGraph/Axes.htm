Axes Tab

Currently 3 axes (scale and titles) can be displayed around the graph; X (below the graph), Y1 (to the left of the graph) and Y2 (to the right of the graph).  Series on Y3 axes and higher will be shown on the graph and legend, but without the scale or titles.

 

Axis

The Axes for your current graph are displayed in this list box.  The settings for the selected Axis will be displayed below, where they can be edited.

 

[Add Y Axis]

Axes are usually added automatically when the series are selected (one axis is added for each type of unit displayed on the graph.  Sometimes two series share the same units but require a different scale.  In this case, press [Add Y Axis], go to the "Series" tab, select the series to switch to this axis and then adjust the "Y Axis" to the one you just created.  This new axis will now have its own scale.

 

Size

Width / Height

This adjusts the distance of the current axis (displayed above next to Axis) from the margin of the graph display.  Click up or down arrows to modify the location of the X or Y axis, which will compress or expand the viewable area.

 

Axis Title

Text

This adjusts the text in the current axis title (displayed above next to Axis).

 

The text here is a single line, it can contain the following items which will be automatically replaced with series information:

 

 

[XSeries] The series title associated with the X axis
[Y1Series] The series title associated with the Y1 axis
[Y2Series] The series title associated with the Y2 axis
[XUnit] The units associated with the X axis
[Y2Unit] The units associated with the Y1 axis
[Y2Unit] The units associated with the Y2 axis

 

The series titles are created by combining the names of all series linked to the axis.  The titles are matched word by word starting from the beginning.  The matched words become the series title.

Scale Labels

Format

The format list contains "Automatic" and some predefined number formats.  The predefined formats are made up of the following symbols:

 

#

Digit placeholder. Display a digit or nothing.

0

 Digit placeholder. Display a digit or a zero.

.

Decimal placeholder.

,

Thousand separator.

$

Prefix number with a dollar sign.

Increment

The increment is used to specify the space between scale labels and grid lines.  Entering 0 will cause Plotsy to automatically choose an increment value.

 

Divisor

The divisor can be used to simplify graphs with very large or very small units.  It adjusts the magnitude of the scale labels and then updates the axis units labels accordingly.  Plotsy defaults to "Automatic" which will start scaling labels when they can all be divided by 100.  Set divisor to 1 to disable this feature.

 

 

Grid Lines

Tick marks and grid lines can be configured and displayed for the X, Y1 and Y2 axes.  They are placed at the increment spaced by the step value.

Minor

Additional tick marks can be added between the normal tick marks.  The only choices are none, halves., fifths and tenths.

 

 

Scale Limits

[x] Override Scale check box / Minimum / Maximum

Usually a graph automatically adjust the scale so all values on the graph fit.  The scale can be customized by checking on the override scale check box and then adjusting the minimum and maximum settings.

 

[x] Lock Scale with X Axis

This feature is used for displaying maps, it causes the current y axis to have the same printed scale as the x axis scale.

 

 

[Promote to Y1 / Y2]

As only axis Y1 and Y2 are displayed on the graph, other Y axis can be promoted to these positions.

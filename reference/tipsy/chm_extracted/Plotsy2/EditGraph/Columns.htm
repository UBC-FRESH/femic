Add or Remove Series

Clicking on the Select Series button from the Side Bar will bring up the Add or Remove Series dialogue.  

 

A "series" is a column of data or row of data from a data source that can be graphed (the term "series" is commonly used in spreadsheet programs such as Excel).  The Add or Remove Series dialogue was developed to allow users to select the column or row of data for graphing.  It was designed to match the Custom View column selector in TIPSY.  

 

Each time you create a graph in TIPSY or TASS, you create and send a full set of data for graphing in Plotsy.  This data source you generated in the parent application will be listed in the "Column Group" list box at the top of this dialogue.  The series of data associated with the data source that can be graphed is listed in the box labelled "Columns".

 

To add or remove the series you wish to graph, select on an item from the "Column Group" and then select the series from the "Column" you want to graph.  Click the Add button.  This will move the item to the "Selected Columns" box in preparation for graphing.  Use the Remove button to reverse this process.  Multiple series of data can be selected and added (or removed) for graphing.  Items listed in the "Selected Columns" box will be graphed on top of each other.

 

Click OK to leave this dialogue and return to Plotsy's main screen.  The items you selected will be plotted.  You can return and adjust this as many times as you wish.

 

Column Group

Groups of columns can be defined in the Application Type / Column File.  Each column can be a member of any number of groups.  The column group controls what columns are displayed in the "Columns" list.

 

Columns

A list of available columns from the Column Group.  Once a column has been added to the "Selected Columns" list, it won't display in the "Columns" list.

 

Sort Alphabetically

Sorts the "Column" list alphabetically.

 

Add

Transfers the selected columns from the "Columns" list to the "Selected Columns" list.

 

Add All

Transfers all columns from the "Columns" list to the "Selected Columns" list.

 

Remove

Transfers the selected columns from the "Selected Columns" list to the "Columns" list.

 

Remove All

Transfers all columns from the "Selected Columns" list to the "Columns" list.

 

Selected Columns

A list of all columns that have been selected to display on the graph.

 

Up

Moves the selected items in the "Selected Columns" list up 1 position.

 

Down

Moves the selected items in the "Selected Columns" list down 1 position.

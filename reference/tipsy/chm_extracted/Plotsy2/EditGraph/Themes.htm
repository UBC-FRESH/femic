Add or Remove Themes

This screen is similar to the Add or Remove Series.

 

Themes

A list of available Themes available.  Once a theme has been added to the "Selected Themes" list, it won't display in the "Themes" list.

 

Add

Transfers the selected themes from the "Themes" list to the "Selected Themes" list.

 

Add All

Transfers all themes from the "Themes" list to the "Selected Themes" list.

 

Remove

Transfers the selected themes from the "Selected Themes" list to the "Themes" list.

 

Remove All

Transfers all themes from the "Selected Themes" list to the "Themes" list.

 

Selected Themes

A list of all columns that have been selected to display on the graph.

 

Up

Moves the selected items in the "Selected Themes" list up 1 position.

 

Down

Moves the selected items in the "Selected Themes" list down 1 position.

Edit Graph Template

You can edit how your graph is displayed by editing the graph templates.  

To do this, select the data source you wish to work with from the data source screen at the top of the side bar.  This will activate the graph template for that source.  Each type of data source has a graph template; there are three default graph templates to choose from in Plotsy,  one for a line graph, a bar chart, or a stem map.

Next, to edit a graph template, click on this button in either the Graph menu item, the toolbar or the button in the Graph Template box on the side bar.  This will bring up the graph template screen.

The edit graph template screen is split into three tabs:

  1. Graph

  2. Axes

  3. Series (default tab)

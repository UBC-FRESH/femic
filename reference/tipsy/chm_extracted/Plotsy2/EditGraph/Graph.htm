Graph Tab

Click on the Graph tab to edit the graph title and graph template information.  

Title

Text

This section is used for editing the text displayed on your graph title, including the format.  

 

There are two rows of information displayed at the top of the graph.  The first row is the name of the graph, which is usually the X Axis and Y Axes.  Below that is the name of your data source.

 

Items in [Square Brackets] are used to lookup values from fields and settings.  The title can contain more than one line (press <Ctrl> and <Enter> buttons on the keyboard to move to the next line).

 

The following items can be used in the Graph Title Text:

 

[XAxis] [Y1Axis] [Y2Axis] is replaced with the text from the Axis Title.

[DataSource]

 is replaced with the Data Source description.

 

Currently 3 axes (scale and titles) can be displayed around the graph; X (below the graph), Y1 (to the left of the graph) and Y2 (to the right of the graph).   See also Axes.

Graph Template Information

This section shows basic information about the graph template including what application type it was created with and the last time it was saved.

 

Template Name

The template name will be displayed in the Graph Template list.  If the template name is blank, the title will be displayed.  You can create your own template names.

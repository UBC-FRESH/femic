Series/Theme

Series / Theme list

Selecting items in this list will display it corresponding properties in Series / Theme Properties on the right.  The Series / Theme list is a multi-select list.  If multiple items are selected only the properties for the first one will be displayed, but changing any of the properties will affect all selected items.  The following columns are displayed in this list:

  1. A preview image of how the item will be displayed

  2. Y Axis and Units, or if a bar graph then either "Bar" or "Cluster"

  3. Series name

 

[Select Series]

This button brings up the Add or Remove Series window.

 

[Select Theme]

This button brings up the Add or Remove Series window.

 

[Add Theme]

This button will add a new blank theme to the list.

 

Series / Theme Properties

Label

The name to display on the legend.  The following tokens can be used:

 

[ColName] The Column name specified in the Application Type for the Y Position column.
[ThemeStr] The Filter text:

[ThemeCol]

 The Column name specified in the Application Type for the Theme.

 

 

 

Y Axis (1,2 and more)

Set which axis to display this series on.

 

Y Position

Select the column that will be used to calculate the y position on the graph.

 

Theme

Select the column to theme this series on.

 

Filter

The filter can be entered as either a single word (when the theme type is text) or a number.  A range of numbers can be add by using the keyword "to", e.g. "0 to 10".  Multiple words, numbers and ranges can be delimited by commas.

 

Type

The Type specifies how to draw the graph, either points, lines, or bars.  Not all types are available for all Graph Types.   When a type is not available or when it is turned off an X will appear through the preview.

 

Colour / Line Style

See styles

 

Symbol

Use this list to select the type of symbol to display.  The symbols will only display if the type contains a point.

 

Size

See measurements

Data Source File (.tdt)

 

A Data Source is a tab delimited text file that can contain the following information:

  1. AppType – The name of a Application Type / Column (.tcl)  file to use.

  2. View – Information about what is currently displayed in the parent application including: title, columns visible, x axis and theme by axis.

  3. Header – A plain text description that isn’t processed by Plotsy but can be exported and displayed by the user.

  4. Run – A list of settings (the name of the setting and its associated value).  These pairs are processed by Plotsy and can be compared with other run data so the differences can be displayed to the user

  5. ColID (optional)  – When the Data columns are not in the same order as the Application Type / Column (.tcl) file or you are using a partial data set, this section redirects the columns to the correct order.

  6. Data – A table (flat file) of the values for each column and row.

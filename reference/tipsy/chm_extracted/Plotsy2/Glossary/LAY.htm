Page Layout File (.lay)

 

Currently page layouts cannot be created within Plotsy.   All page layouts in the application folder will be loaded automatically.  User defined page layouts can be placed in the “my documents\Plotsy” folder.

 

Layout files specify the location on the page of the following zones:

  1. Header / Footer

  2. Graph

  3. Legend

  4. Table (future)

 

Each zone must be defined by a measurement for its four boundaries relative to one of the page edges or the other zone measurement.   Positive numbers are relative to the left and top edge; negative numbers are relative to the right and bottom edge.   Page units are in 1/1000”

 

Pens defined in the style library can be used within the template.

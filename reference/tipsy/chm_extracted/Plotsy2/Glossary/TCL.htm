Application Type / Column File (.tcl)

The Application Type / Column File describes the format of the data exported from an application.  Applications with data in one table may export all data in a single format.  Some applications including TIPSY and TASS require multiple formats.  Some reasons for having multiple tables:

  1. The rows in one table don’t match the rows in another table. (i.e. a stem map and a yield table)
  2. The data is calculated separately from the original data (i.e. snags are calculated using a separate model after  the main database has been calculated)

 

The  Application Type / Column file specifies what columns are to be expected from the parent application, including titles, units and formatting.   This file only needs to be created once for each Type.  It can be created by the Parent Application, or just included in applications folder.  A Parent Application is a program like TIPSY or TASS that automatically launches Plotsy and sends data to it.

 

The format of this file is a tab delimited text file.  Lines that start with a single quote are comments and ignored by the program.  Lines that start with an asterisk are section headers.  Descriptions that span multiple lines should be separated by the pipe symbol “|”.

 

The file can contain these sections:

  1. Columns – details about the columns including: name, units, number of decimal places and width.
  2. Headers – used to span titles above like columns
  3. Groups – used to filter like columns in the user interface.

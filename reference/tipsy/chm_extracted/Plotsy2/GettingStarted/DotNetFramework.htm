Installing the .NET Framework

The .NET Framework can be downloaded directly from Microsoft, or even installed using Windows Update / Microsoft update:

 

 

Using Windows Update:

 

http://update.microsoft.com/microsoftupdate/v6/default.aspx?ln=en

Click "Custom"

Click "Software - Optional"

Select "Microsoft .NET Framework 3.5: x86"  

Then press "Install Updates"

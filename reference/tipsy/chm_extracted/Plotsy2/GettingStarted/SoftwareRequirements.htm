Software Requirements

Plotsy has been tested on Windows XP SP3 (32 bit), Windows Vista (32 & 64 bit) (including standard MOFR configuration as a non administrator), and Windows 7 (32 & 64 bit).

 

Plotsy requires Microsoft's .NET Framework (at least version 2.0).  Microsoft Vista and Windows 7 come with the .NET Framework as part of the operating systems.  Some Microsoft XP users may have to install the .NET Framework.

Graphing in Plotsy

Plotsy is a flexible and powerful graphing utility for use in displaying and analyzing growth and yield data.  It provides basic graphing functionality to meet common graphing needs, and advanced analytical graphing features for power users.  It provides users maximum flexibility to view graphs and data, overlay information, to adjust how graphs are presented, and for exporting of data and high quality graphic images for reporting.

 

Plotsy is used for displaying graphs that have been prepared in the parent applications such as TIPSY and TASS.  You must first create the data and select the graphing feature icon in the parent application to generate a graph in Plotsy.  Please refer to the Help in these applications to learn how to create graphs in them.  

 

Three basic types of graphs that can be displayed in Plotsy :

 

  • Line Graphs

  • Bar Charts

  • Stem Maps

Each type of graph has a Graph Template, which describes the setup features for the graph.

 

The graph and data associated with the graph you generate will be sent to Plotsy to display.  You can then select the fields of data and graphing formats in Plotsy.  Default graphing templates and formats are provided with Plotsy, but you may adjust most of these with Plotsy's features.

 

Information on the graph you created is displayed in the Data Source box and Graph Template box in the Side Bar area of Plotsy's main screen, see Side Bar Features.  

 

You can also view the data sent to Plotsy using the View Data Source feature, see View Data Source.  

 

You can edit how information is displayed on the graph, see Edit Graph.

 

If you have an existing graph saved from Plotsy, you may load the graph using the Open Graph feature under the File menu.

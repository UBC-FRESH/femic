Screen Layout

Plotsy’s main screen contains:

 

  1. Menu – access to all functions under File, Edit, View, Graph and Help

  2. Tool Bar – quick access to commonly used functions which are also located in the menu.  Hovering your mouse over the icon will display the feature's name.

  3. Side Bar – the side bar is the work area on the left side of the main Plotsy screen.  It is used for selecting the Data Source, Graph Template and Screen Layout.

  4. Graph display area - the right side of the screen is the graph display area.

  5. Scroll Bar graph display control – when multiple runs are selected (highlighted) in the Data Source window, move the scroll bar up or down to graph and display different runs.  Alternately, selecting the run in the Data Source window will display the run.

View Data Source

Click the View Data Source button on the menu (under Graph) or on the toolbar to display the table of data for the data source highlighted in the Data Source box on the Side Bar.

 

This screen is used for viewing and exporting data.  Data can not be edited here, or anywhere else within Plotsy.

 

Copy

Copies the Header information and the data to the clipboard.  This data can then be pasted into other applications like Excel.

 

Export ASCII

Saves the displayed data source to a text file.

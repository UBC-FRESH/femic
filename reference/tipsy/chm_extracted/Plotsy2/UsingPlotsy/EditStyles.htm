Edit Styles

You can edit the graph line types and characters by clicking the Edit Styles button in either the menu under Graph, or from the toolbar.  This will bring up the Styles dialogue list.

Styles

Three types of styles are available in Plotsy for editing:

  • Colours

  • Line Styles

  • Fonts

To edit a style, either double click on the preview of the style, or select the style and press the edit button.

 

To rename a style either double click on the name of the style, or select the style and press the rename button.

 

If you make changes to the styles, you will be prompted to save the styles as the new defaults.

 

Each style is identified by its name.  Plotsy uses these names throughout the program whenever a colour, line style, or font is needed.

 

A styles.txt file is stored in the application path.  It is loaded when Plotsy starts up.

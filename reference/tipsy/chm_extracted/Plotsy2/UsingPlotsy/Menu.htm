Menu Items

Plotsy uses standard Microsoft Windows commands, features and conventions, including Menu items and Toolbars.  The following features are included in the menu items.

File

The File menu supports basic functionality for opening, saving, exporting, printing and displays recently used files.  These are described below.

Open Graph

Select Open Graph to identify and open a saved graph in Plotsy.  It is used to open a graph file (.gph) created in Plotsy.  Plotsy only supports .gph files.  For more information on data stored in the Graph file, see Graph file (.gph)

 

Open Data Source

Opens a Data Source file manually.   Usually this feature is not needed, because when Plotsy is used with an application like TIPSY, that application sends the data source to Plotsy automatically.  For more information on data stored in the data source file see Data Source file (.tdt).

 

Open Graph Template

Opens a Graph Template file (.grt).  See also Graph Template in  Side Bar Features.

 

Save Graph

Used to save a Graph (.gph) file or a Data Source (.tdt) file for use after the parent application has ended.

 

Save Graph Template

Saves a Graph Template file (.grt).  See also Graph Template in  Side Bar Features.

 

Export Graph

Saves the current graph image in one of the following formats:

  • Enhanced Metafile (.emf) – Usually produces the best quality image for importing into other software.

  • W3C Portable Network Graphics (.png)

  • Graphics Interchange Format (.gif)

  • Joint Photographic Experts Group (.jpg)

  • Tagged Image File Format (.tif)

 

Export Data Source

Sends the selected data source  to a text file.  This feature can also be activated from the View Data Source screen

 

Page Setup

Plotsy displays the graph based on the currently selected paper.  This feature can be used to change the paper size and orientation.  

 

Margins are ignored as they are calculated using the current Page Layout.  See Page Layouts for more information.

 

Print Graph / Print Preview

Multiple graphs can be printed.  Simply select multiple data sources and click Print Graph..

 

Recent Files

Displays the ten most recent graph files loaded or saved.  

 

Exit

Closes the Plotsy program.  Deletes all the data source files in the users TEMP\Plotsy folder.

 

 

Edit

Copy Graph Image

This feature copies the graph image to the clipboard for pasting into other applications.  Higher quality graphs can usually be created by exporting the EMF file.

 

 

View

Tool Bar

The Tool Bar can be hidden by un-checking the tool bar menu item in the view menu.

Help

Contents / Index / Search

The Help feature loads the Plotsy help file and goes to the specified section chosen by the user.  

 

Context sensitive help is also available by pressing F1.  

 

By default in Windows, help files must reside on a local drive otherwise the content maybe blocked.

 

About

Displays information on Plotsy's version and developer contacts.

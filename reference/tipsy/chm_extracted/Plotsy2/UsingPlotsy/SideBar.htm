Side Bar Features

The side bar features are located along the left side of the Plotsy screen .  These are the main controls for displaying graphs in Plotsy.

Data Source

The Data Source box displays a list of currently loaded graphs, bar charts and stem maps.  Click on one of the data sources to display your graph.  

 

One or more data source can be selected at the same time.  To view multiple data sources, highlight the data sources.  You can scroll through the highlighted graphs using the right scroll bar.

 

When the data source is selected it automatically selects the associated graph template (shown in the dialogue below under Graph Template) and greys out graph templates that can not be used with it.  If no template has been used with this data source, then Plotsy searches for the last one used that was generated using the same parent application and view.  If no template is found then Plotsy will start the process of creating a new one.

 

A context menu is available by right clicking on a data source.  The menu includes the following features:

  • View Data Source

  • Rename Data Source Description

  • Delete Data Source

 

You can also double click on a data source to rename it.

 

See also the definition of a Data Source file for a description of information contained in a data source file.

 

 

Graph Template

The Graph Template box lists out the various graph templates available.  There are three basic types of graphs that can be displayed in Plotsy.  These are prepared in the parent applications such as TIPSY and TASS.  Please refer to the Help in these applications to learn how to create graphs in them:

 

  • Line Graphs

  • Bar Charts

  • Stem Maps

 

A Graph Template describes the format of the graph, its axes and the series (rows or columns) of data that is displayed.  There is a different graph template for a line graph, a bar chart and a stem map.  

 

Graph templates will be greyed out if they are not usable with the currently selected data source.

 

To edit a graph, select the graph and right click.  This will bring up the list of features that may be edited.  You can also click on the button labelled "Edit Graph Template".

 

A context menu is available by right clicking on a graph template.  The menu includes the following features:

  • New Graph Template

  • Edit Graph Template

  • Select Series

  • Select Theme

  • Delete Graph Template

  • Save Graph Template

 

New Graph Button

This button creates a new graph template for the selected type.  Depending on the type of data you are working with, you will either prompted to select the Series or Themes to add to the graph.

 

Select Series Button

To select a series of data to graph, click the Select Series button.  This will bring up the  Add or Remove Series dialogue.  

 

A "series" is a column of data or row of data from a data source that can be graphed (the term "series" is commonly used in spreadsheet programs such as Excel).  The Add or Remove Series dialogue was developed to allow users to select the column or row of data for graphing.  It was designed to match the Custom View column selector in TIPSY.  (Note: it is only displayed if the graph does not have a View Theme Column Id.)

 

Select Theme Button

This button is used for selecting themes from the data you wish to display.   This button displays the Add or Remove Theme dialog.  It is only displayed if the graph has a View Theme Column Id.  The only graphs that can be themed are Bar Charts and Stem Maps.

 

Edit Graph Template Button

Opens the Edit Graph Template dialog box.  The Edit Graph Template section describes how each setting works.

 

 

See also the definition of a Graph Template file for a description of information contained in a graph template file.

 

Screen Layout

The Screen Layout box describes the layout for viewing one or more graphs (or bar charts or stem maps).  You can view multiples of similar type of graph/chart/stem map.

 

Five options are currently available for displaying graphs.

  1. [Full Screen] – Normal mode, display one graph

  2. [Tile Horizontally] – Display two graphs, one above the other.

  3. [Tile Vertically] – Display two graphs, side by side.

  4. [Tiled] – Display four graphs.

  5. [Overlay] – Overlay multiple graphs on top of each other.

 

Graph Only (check box)

By default, Plotsy will display your graph with borders.  Selecting "Graph Only" will remove borders and display more graph space.  The graph only feature can be used to maximize the graph to the display area.  

 

The graph's aspect ratio is determined by the page layout and the current printer settings.  See Page Layouts for more information.

 

Force selected graphs to same scale (checkbox)

When viewing (or printing) multiple graphs, this feature scales the axes to accommodate all the selected data sources.

 

Overlay Method (list)

When the screen layout is set to Overlay, this feature determines how the multiple runs will be displayed.   The current options are:

  1. Lighter – Keeps same line types and colours for all data sources, but fades colours of all but the first data source, useful when overlaying fewer graphs with multiple lines.

  2. Colours – Adjusts the colour of all lines on each data source to match, but be different by data source.  Useful when overlaying more graphs with fewer lines.

  3. Line Types – Similar to colours, but adjusts the line type instead of the colour.

 

Page Layout (list)

This feature is used for setting where each part of the graph is displayed on the current printer page.  See Page Layouts for more information.  The page layout format provided with Plotsy includes:

 

  1. Normal - the standard layout for viewing and printing graphs.  This includes the borders.

  2. Square - this removes the borders to maximize the viewable graph size.

  3. With Header and Footer - leave room for headers and footers.

Note that the margins can be set by clicking on the Edit Graph Template button and changing the axes under the Axes tab.  See also Axes.

Biomass Pricing Background

FAN$IER's default values for biomass are based on the typical industry value for hog fuel in 2010.  An average value is applied to each tree biomass component.

Biomass values are typically tied to residual values from wood waste.  Wood biomass is predominant used for fuel, either as green chips for hog fuel/gasification or chips for use in manufacturing wood pellets or wood briquettes. Smaller volumes tend to go to use as landscaping material, horse tracks and livestock bedding.  Biomass values vary widely throughout BC 1.

The economic viability of creating biomass from a stand depends to a large extent on the delivered cost (including harvesting transportation and chipping).  Users are encouraged to consider using localized values.

A higher value from green bole-wood biomass for use as pulp and OSB chips can be specified by overriding bole-wood defaults accordingly.

Biomass is typically harvested in addition to logs, as a byproduct of residual timber from slash and roadside debris.  To analyze biomass as a byproduct of logs or lumber, a special product-based yield profile must be created.  Contact User Support for details.

1 Source: The discussion of biomass values is based on Enfor Consultants Ltd., M. Greig, March 2011.  More information is available at http://www.enfor.com/?Page=\energy\bioenergy\

CO2e Pricing Background

FAN$IER's default values for carbon dioxide equivalents (CO2e) represent the value in $/tonne CO2e that industry might be paid for a forest carbon offset project in 2011 by the BC Provincial Government or its agents 2.  Since transaction data is confidential, it is not possible to get specific values.  An average value is applied to each tree biomass component.

Note that the estimated volume per hectare of CO2e is “gross” tonnes before accounting for other carbon emissions and reductions from associated silviculture activities.  It is therefore the theoretical maximum CO2e stored.

There are several transaction costs that should be accounted for, in addition to the values for CO2e.  These can be included in the Costs Tab under various “Other” sections.  Users can account for costs including offset project planning, validation, periodic verification, ongoing stand maintenance, insurance, etc.

2 Source: The discussion of CO2e values is based on Enfor Consultants Ltd., M. Greig, March 2011.  More information is available at http://www.enfor.com/?Page=\co2\carbon\

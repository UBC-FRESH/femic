The Benefits Tab controls and reports the calculation of stand value based on the Products group selected in the Main Settings section of the Main Screen.  Tables report benefits by harvest, species, and sub-product type.

Products Group

The title of the selected Products group is displayed at the top of the tab.  Current options include:

Biomass and CO2e

Logs

Lumber and Mill Residues

Key concepts:  FAN$IER's default prices are initially displayed in the Product Value Tables.  Users can modify these defaults using either the Adjustment Factors or Rate Adjustments described below.  Adjustment Factors are intended as coarse alternatives to the Rate Adjustment capabilities incorporated in the product value tables themselves.   Adjustment factors will only be applied to default rates, not adjusted rates.  

Price Adjustment Factors

A product price adjustment factor is a simple value multiplier with a default of 1.00 (no change).   Clicking on the adjustment factor value for each of the sub-products listed in the table opens the Adjustment Factor dialog box to edit the value.

Product Value Tables

Product values are reported in tables by harvest age, product sub-categories,  These tables report Quantity (regime yield), Rate (value per unit), and the computed Benefits (value per hectare), both undiscounted and discounted.  Column totals are also provided,

Rate Adjustments

Individual Rates (value per unit) in the tables can be adjusted by clicking an individual Rate cell so that the Override Product Value dialog box appears.  Rate adjustments take priority over the Adjustment Factors above.

Copying, Saving, Printing

The current contents of this tab can be copied, saved, or printed by right-clicking within the tab.

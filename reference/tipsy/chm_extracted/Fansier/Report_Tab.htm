Report Tab

The Report Tab contains regime information and economics data in report format.

Report Sections

The Report contains the following sections:

  • Results - Regime information and analysis results.

  • Harvest Summary - a list of harvests by age and the volume removed

  • Discount Assumptions - the discount assumptions used for this report.

  • Costs - a list of costs by section and activity.

  • Jobs - a table of jobs (employment, from a TIPSY regime file).  Jobs data are only reported, they are not analyzed by FAN$IER..

  • Benefits - a summary of benefits.

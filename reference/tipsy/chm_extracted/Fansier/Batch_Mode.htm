Batch

Batch Mode enables processing of multiple existing Regime (.RGM) files using FAN$IER's default economic setting, or using custom economics settings from Economics (.ECO) files.  Once all required user inputs have been set, the Start Batch button at the bottom of the window becomes active.

See File Types for instructions on creating .RGM and .ECO files.

Key Concept:  Batch settings generate a potentially large factorial matrix of individual economic analyses defined as:

# of RGM files  X  # of ECO files X  # of Discount Assumptions  X  # of Product Groups  X  # of Harvest Ages  =  the total # of individual analyses reported

Regime Files

Use the column of buttons to the right to add or delete .RGM files from the batch processing list.

Economics Files

Select "Use defaults" to apply FAN$IER's default economic settings to all the .RGM files.  No .ECO files are needed in this case, and it only counts as one "ECO file" in the factorial matrix.

To use custom economic settings from .ECO file(s) instead, click the Add button to select one or more existing .ECO files.  Click the Clear button to remove all files from the list.

Location Override

Optionally, select location setting(s) to override those in each .RGM file.

Discount Assumptions

Select one or more Discount Assumptions.  Create and edit custom definitions using the icon buttons on the right.

Product Groups

Select one or more Product Groups.  Listed options are determined from the .RGM files.    

Harvest Ages

Select one or more Harvest Age definitions.  Listed options are determined from the .RGM files.   

Reports

Select the Report Path (directory path) where report(s) are to be saved.

Enter a unique Run Identifier to include in report filename(s), and select a File Type (file extension).

Check or uncheck options for producing Short and/or Long Reports, and including comma separators and Product Columns.

Batch

Once all required user inputs have been set, the Start Batch button becomes active.  If the button is inactive, make sure at least one option is selected from every category within the factorial matrix.

The Print Preview Short Report button is enabled only after a short report has been created.

Additional runs can be made with the same or altered settings.   Unless a new run identifier or report path is defined, the last file created will be overwritten.

Costs for individual activities are viewed and edited within the Cost Tab.  Cost activities are grouped into the following six (6) categories:

  • Silviculture Treatment Costs

  • Harvesting Costs

  • Commercial Thin Harvesting Additives

  • Roads and Infrastructure Costs

  • Annual Costs

  • Manufacturing Costs

Key concept:  Detailed information about default costs and cost options are viewed through the Activity Costs & Product Prices viewer.  Changes to these default costs can be made within each Cost Tab activity.

Individual Activities

Under each main section heading are individual activities (e.g., planting cost, tree-to-truck costs, etc) in bold letters.  The selected cost method appears to the right of the activity title.   The current cost values associated with each activity are reported in the far right margin.

Activity Status Boxes

a small box appear to the left of every activity.  An empty box indicates costs associated with that activity are not included in the current analysis. Clicking an empty box places a check in the box to include the activity cost in the analyses.

a check indicates activity costs are included in the current analyses.  Certain costs associated with activities applied within the growth and yield model  (e.g., planting, fertilization, etc) are activated (checked) automatically.  

Key Concept: activating (checking) a silviculture treatment cost does not activate the associated biological treatment (yield) response.  Yield response can only be applied through the growth and yield model.

an "x" indicates the activity cannot be activated because the associated yield response was not applied to the regime through growth and yield model.  To apply the treatment, return to the growth and yield model, apply the silviculture treatment, and re-send the regime to FAN$IER.

Activity Cost Details and Functions

Clicking on activity title displays activity cost settings, which frequently include a cost method drop-down pick-list plus box(es) for any user input(s) required for the selected cost method.

clicking the "?" box displays the Activity Cost defaults and options specific to that activity.

clicking the "f" box displays function details for the currently selected cost method.  Note that certain input variables derived from the growth and yield model are locked and cannot be edited in FAN$IER.  

Add/delete Multiple Activities

Some cost activities can be applied multiple times;

 Click the plus symbol to the left of the activity status box to create another incidence of the same activity.   Settings for these extra activities are edited independently.

Click the minus symbol to delete an extra activity.

FAN$IER automatically creates extra activities to match activities applied multiple times the growth and yield model.

The Early Stand Replacement (ESR) option is invisible in default mode.  Once activated from the Edit Menu, it appears as a header line within the Compare Tab.

The ESR option was originally created to support FFT analysis of Early Stand Replacement scenarios that involve timber sales (ITSLs) of heavily-damaged stands (e.g., fire, disease or insects).   However, FFT no longer uses FAN$IER's ESR option.   Instead, ITSL development costs are entered as "Other Silviculture Costs" within the Cost Tab of the Treated Case.

As currently configured, the ESR option supports the analysis of replacing an existing stand before it meets normal harvest criteria (e.g., CMAI).   The Base Case represents the existing stand and the Treated Case represents the replacement stand.

After sending Base and Treated Case regimes to the Compare tab, open the Early Stand Replacement dialogue box by clicking on the “no (click here)”  cell in the treated-case column.

Activating ESR options

Check the Early Stand Replacement box at the top to toggle application on and off.

ESR Harvesting Costs and Benefits

Calculate Stand Replacement Costs from another Regime

This option draws early harvest costs and revenues from the selected regime, the Base Case by default.  The accompanying Products selection allows different products to be targeted in the early harvest (e.g., biomass).

User Specified Stand Replacement Costs and Benefits

Alternatively, the user can specify lump-sum values for harvest benefits and/or costs.  Costs should include the full suite of harvesting and processing (e.g., milling) costs similar to those normally included by FAN$IER.  If the damaged stand is mechanically destroyed without generating harvest revenue, enter only the cost of mechanical destruction and set benefits to zero.  Note, these values must entered in 2006 dollars (i.e., corrected for inflation at 2%/yr).

User Specified Silviculture Costs

Alternatively, the user can specify a lump-sum value that overrides the Cost Tab values.  Note, this value must entered in 2006 dollars (i.e., corrected for inflation at 2%/yr).

The Compare Tab provides a side-by-side comparison of two or more scenarios; each column represents one scenario.  Scenarios can vary by growth and yield input (GY regime), economic settings, or both.

Silviculture investment analyses commonly compare treated and untreated regimes for the same stand and economic assumptions, but other comparisons are possible, too.

Within each scenario, benefits and costs are discounted to the selected age at base year.  NPV and IRR are calculated from this base year, but SV is always calculated for the full rotation.  I.e.,  costs incurred prior to the base age are treated as sunk costs and ignored in NPV and IRR calculations.

Adding a Scenario (column)

Scenarios are added to the Compare Tab by clicking the Send to Compare button in the Main Settings area of FAN$IER's Main Screen.  But first, ensure the scenario has been completely configured within the Main Settings area (incl. Discount Assumptions), Regime, Costs, and Benefits Tabs.

Up to five (5) scenarios can be displayed at once.  Adding a sixth scenario displaces the first.

Removing a Scenario (column)

To remove a column, click the "X" at the top of that column.

Comparison Column

A Comparison column appears only when two scenarios are being displayed.  When this occurs, the first column is labeled 'Base Case' and the second labeled 'Treated Case'.  Normally, the Comparison column simply reports the difference (by subtraction) between each pair of row values to the left, Incremental IRR is the exception.

Moving Columns

Clicking the arrow at the top of a column moves that column into the left most column position (base case position).  This is mainly used to correct scenario assignment errors, i.e., reverse the scenarios assigned to base and treated cases.

Adjusting Scenario Settings

Changes to scenario settings from within the Compare Tab are limited to settings in the Main Settings area (incl. Discount Assumptions).

To access and edit these settings for one of the scenarios (columns):

  1. Click on the scenario's column header (the top 6 light-blue rows).  The column header and Main Settings area will both change color to orange, indicating changes can be made to the Main Settings.

  2. Changes made to the Main Settings will also be reflected in the corresponding column header values, and values in the remaining rows of that column will be updated accordingly.

  3. To turn off edit mode, click on the column header again.

FFT Features

The following three Compare Tab features support unique aspects of the Return on Investment (ROI) analysis procedures used by the Ministry's Forests for Tomorrow (FFT) Program:

  • Incremental Internal Rate of Return (IRR) with sunk costs ignored via Age at Base Year.

  • Support for Early Stand Replacement scenarios.

  • Provision for user ROI analysis strategy documentation, i.e., the Description text for each regime from the Regime Tab is included at the top of the Compare Tab report.

Copying, Saving, Printing

The current contents of this tab can be copied, saved, or printed by right-clicking within the tab.

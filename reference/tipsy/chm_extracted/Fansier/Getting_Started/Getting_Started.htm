3 Steps to using FAN$IER

There are three (3) basics steps to conducting silviculture investment analyses with FAN$IER:

  1. Silviculture regimes are developed with TIPSY, TASS, or other growth and yield (GY) model capable of producing product-based yield data, e.g., log and lumber yields.  These data are then loaded into FAN$IER.  Instructions below.

  2. In FAN$IER, economic settings are then configured for each of the simulated silviculture regimes above.   This step involves reviewing and/or editing the default settings accessible through FAN$IER's Main Screen.

    Key concepts to understand:

    • A FAN$IER Project consists of one or more Regimes.  Regimes can represent different stands, or more commonly, different silvicultural alternatives for the same stand, e.g., treated and untreated scenarios.  The analysis results from multiple regimes can then be compared side-by-side in the Compare Tab.

    • A Project is saved as a .FNS file.  This file contains all the data and settings for each Regime in the Project.  This includes product-based yield data and other pertinent regime information from the GY model, plus all the economic settings (e.g., discount assumptions, costs and prices) from FAN$IER, for each Regime.  Opening a .FNS file loads these data and settings, and displays the results of analyses, as configured at the time the file was last saved.

    • FAN$IER's Main Screen provides access to all settings and analysis results for one Regime at a time, in order to review and/or edit them.  The Compare Tab is the one exception to this one Regime rule.

    • Analysis results are instantly updated when changes are made to individual settings.

  3. Analysis results are viewed, saved, and printed through Tabs on FAN$IER's Main Screen (the next stop on a quick tour).

Note:A large number of analyses can also be conducted simultaneously using Batch Mode.

Using FAN$IER with TIPSY

Create a regime in TIPSY, then send it to FAN$IER using the icon on the TIPSY Tool Bar. Repeat for additional regimes.  FAN$IER can load and compare multiple regimes this way.

Back to Top

Using FAN$IER with TASS

Product-based yield data are available through the new interactive version of TASS (TASS III) and with Custom TASS runs requested through User Support.

When using TASS III, create a regime and run the simulation, then click the icon to open FAN$IER Export, adjust the settings, and finally click "Continue to FAN$IER" to open FANSIER and load the regime data.  Repeat for additional regimes.  FAN$IER can load and compare multiple regimes this way.

Back to Top

Using FAN$IER with other GY models

FAN$IER can also be used with other growth and yield models capable of generating product-based yield tables.  But before FAN$IER can utilize these data, they must be reformatted in FAN$IER's .RGM format.  Contact User Support for details.

The Main Menu is located in the upper left corner of the Main Screen window, above the Tool Bar.  It contains four (4) main menu items, which access related commands via pull-down menus.

File menu

File menu commands:

  • New Project:  Creates a new (empty) project in order to receive yield data directly from TIPSY or TASS III, or add existing Regime (.RGM) files.   This step is normally unnecessary when sending data from TIPSY or TASS III.

  • Open:  Opens an existing project, i.e., FAN$IER (.FNS) file.

  • Save:  Saves the current project as a FAN$IER (.FNS) file.

  • Save As:  Used to rename and save the current project, i.e., FAN$IER (.FNS) file.  Also used to save just the project's economic settings by selecting the ECO file type.  ECO files are used in Batch Mode.

  • Rename Regime:  Rename the currently selected Regime within the current project.

  • Remove Regime:  Removes the currently selected Regime from the current project.

  • Import Regime:  Locates an existing Regime (.RGM) file and creates a new Regime in the current project using its data.

  • Export Regime:  Creates a new Regime (.RGM) file based on the currently selected Regime in the current Project.  RGM files are used in Batch Mode.

  • Batch Mode:  Opens the Batch Mode dialogue box to configure batch runs.

  • Print Preview:  Opens an on-screen print-preview window displaying the contents of the currently selected output Tab.

  • Print:  sends the contents of the currently selected output Tab to your system's printer.

  • Recent:  displays a list of recently viewed project files, i.e., FAN$IER (.FNS) files.

  • Exit:  Closes FAN$IER.

Edit menu

Edit menu commands:

  • Copy:  Copies selected text from output Tabs to the Windows Clipboard.

  • Select All:  Selects all text within an output Tab in preparation for Copy.

  • Unlock Regime Variables:  This option is no longer needed and has been deactivated.

  • Show Calendar Year: Toggles on/off display of calender year in tables within output tabs.

  • Show FFT Incremental IRR:  Toggles on/off display of FFT Incremental IRR in the Compare Tab.

  • Show Reinvestment IRR:  Toggles on/off display of Reinvestment (incremental) IRR in the Compare Tab.

  • Show Early Stand Replacement:  Toggles on/off display of the Early Stand Replacement option in the Compare Tab.

Discount Assumptions menu

Discount Assumptions menu commands:

  • Create Discount Assumptions:  Create a new set of Discount Assumptions.

  • Load Discount Assumptions:  Opens and applies an existing (saved) set of Discount Assumptions.

  • Save Discount Assumptions:  Saves the current Discount Assumptions.

  • Edit Discount Assumptions:  Edit the current Discount Assumptions.

  • Remove Discount Assumptions:  Removes the selected Discount Assumptions.

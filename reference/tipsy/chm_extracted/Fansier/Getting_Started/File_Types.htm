File formatting

Three (3) file types are associated with FAN$IER.

FAN$IER (.FNS) files

FAN$IER (.FNS) project files are used in the interactive version of FAN$IER.  This is the main file type associated with FAN$IER in Windows.  When saved, it contains all the yield data and economic settings needed to (re)produce analyses for each regime in the project.

Regime (.RGM) files

Regime (.RGM) files contain the regime description and product-based yield data for a single regime.  They are used in Batch Mode, and they also serve as input files for importing data from other growth and yield models into the interactive version of FAN$IER.

When FAN$IER is called from TIPSY or TASS III, no permanent .RGM file is created.  If .RGM files are needed for Batch Mode, use the File - Export Regime command to open SAVE.

Economics (.ECO) files

Economics (.ECO) files are only used in Batch Mode.  It defines a unique set of economic settings.  When ECO files are selected in Batch Mode, FAN$IER automatically runs each ECO file listed against each RGM file listed.  E.g., 3 ECO files and 3 RGM files will produce 9 separate analyses.  If no ECO files are specified in Batch Mode then FAN$IER's default economic settings are used.

If ECO files are needed for Batch Mode, use the File - Export Regime command to open SAVE and select Save as Type = Batch Mode to save both .RGM and .ECO files at the same time.

File formatting

.RGM and .ECO files are ASCII text files with formatting specific to FAN$IER.  Contact User Support for details.

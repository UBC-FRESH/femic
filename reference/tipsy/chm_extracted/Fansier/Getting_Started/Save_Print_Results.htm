Save & Print Results

The contents of most tabs can be saved, printed, or copied in a variety of formats.  Bring up the pop-up menu below by right clicking on a Tab, and select an option.

  • PDF Report – Creates a PDF of the report.

  • Save Report - Prompts for a filename to save the tab-delimited report as an ASCII text file.

  • CSV Report – Saves the report in Comma Separated Value format for use by spreadsheet programs.

  • Print Report - Sends the report to the printer.

  • Preview Report - Sends the report to a print preview window.

  • Copy - Sends tab-delimited text to the Windows clipboard.  The clipboard contents can then be pasted in to a spreadsheet or other applications.

  • Select All – Selects the entire report in preparation for Copy.

  • Copy as Image – Copies the tab contents as an image file, which can be pasted into another program.

System Requirements

Minimum recommended system requirements:

Windows versions:  XP, Vista, 7, 8

Processor speed and system memory (RAM):  nothing special

Display resolution: nothing special

Available drive storage space:  20MB when installed with TASS III; 120MB with TIPSY.

What's New?

Revision history, current version first:

CURRENT VERSION

  • Revisions to Planting Costs and Tree Improvement Costs:  When Tree Improvement Costs (improved seed costs) are included in User Defined Planting Costs, the user is instructed to also select the new Included in Planting option under Tree Improvement Costs.  This applies a Tree Improvement cost of $0.00 to compensate.

  • Various output reports, including Compare, now report activities with $0.00 cost.

  • Added support for additional Log Grades (E,G,K,L,M).   Note, as before, the appearance of these and other Products in FAN$IER is governed solely by their presence in the RGM input file derived from growth and yield model output.

  • Fixed various bugs, including scrambled lines in the Compare table and PCT/CT cost calculations.  

Version 1.17,   April 5, 2016

  • Revisions to the Early Stand Replacement option.  NOTE: BC Forest for Tomorrow's (FFT) no longer uses this option.   Instead, timber sale (ITSL) development costs are now entered as "Other Silviculture Costs" within the Cost Tab of the Treated Case.

  • Batch revisions

  • enabled editing of location variables in the Regime Tab

  • updated Help

  • bug fixes

Version 1.1  July 4, 2015

Revisions focused in two areas:

  • Added support for product-based yields imported from TASS III.

  • Modifications to the HELP system as follows:

    • Edited and updated HELP content;

    • Converted to a CHM (HTML-based) HELP system, to standardize TASS-family software; and

    • Added the Activity Costs & Product Prices viewer.

Version 1.0  May 10, 2013

FAN$IER (Financial Analysis of Silviculture Investment and Economic Return) replaced the TIPSY Economist, beginning with TIPSY ver. 4.3.  FAN$IER is bundled and distributed with  TIPSY ver. 4.3.

New functionality and improvements include:

  • Integrated data transfer from TIPSYI.  FAN$IER also accepts data from other growth and yield models capable of producing product-based yield tables.

  • Compares multiple regimes at different harvest ages, including age at maximum MAI, NPV, SV, and IRR.

  • Support for return-on-investment (ROI) calculations for the Ministry Forest For Tomorrow (FFT) program, i.e., FFT incremental internal rate of return (IRR) calculations for comparing two regimes.  Visit the FFT ROI website for more information.

  • Support for regimes containing more than one incidence of the same silviculture activity (event), e.g., planting, thinning, fertilization, etc.

  • More product price adjustment options.

  • Projects containing multiple regimes and discount assumption settings can be saved in a single .FNS file.

  • Analysis reports can be saved, copied, printed and/or exported as .txt, .csv or .pdf format files.

  • Supports new TIPSY forest product options including:

    • Three new lumber options

    • Logs by grade

    • Biomass and carbon dioxide equivalent (CO2e).

  • Batch processing mode for large numbers of regimes.

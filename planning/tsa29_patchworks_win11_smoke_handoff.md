## Windows 11 Patchworks smoke steps
1. Pull this branch and update submodules.
2. Open Patchworks and load `output/patchworks/forestmodel.xml`.
3. Confirm all required source tables resolve from `output/patchworks/`.
4. Execute a minimal compile/smoke run (the shortest run that exercises model load, transition logic, and yield ingestion).
5. Export/save run logs from Patchworks.

## Pass checklist
- Model loads without schema/parser errors.
- No missing-table or missing-field errors during load.
- Compile/run starts and completes without fatal errors.
- Yield/action/transition structures appear populated (non-empty) in Patchworks diagnostics.
- Any warnings are recorded and non-fatal.

## Evidence to capture back into repo
Store under `external/femic-tsa29-instance/evidence/patchworks_smoke_win11/`:
- Patchworks run log(s)
- Short markdown summary (`summary.md`) containing:
  - date/time
  - Patchworks version
  - result (`pass`/`fail`)
  - key warnings/errors
  - next fix actions (if fail)
- Optional screenshot(s) of successful compile/run status.

## If fail
Capture exact failing message and the first failing table/field reference; do not patch around it in Windows. Feed that back into FEMIC pipeline logic/data export fixes on this branch.
